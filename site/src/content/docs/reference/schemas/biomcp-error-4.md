BioMCP 1.0.0 prints one JSON object, the reply, for each command. Any command may return `biomcp.error/4` when its arguments or local processing fail. Read this page when your code parses that reply: it shows the fields this schema defines. [Shared types](/reference/schemas/types/) defines the rest.

Invalid commands and local failures return this error reply.

## Fields

A field marked Optional can be missing from a reply. Every other field is always there.

 `query` repeats the request as BioMCP read it.
