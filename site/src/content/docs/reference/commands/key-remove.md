`biomcp key remove` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It removes a stored key. This page lists its usage.

The program's help describes it:

> Remove a stored credential while preserving other settings.

## Usage

```text
biomcp key remove <source>
```

## Arguments

The command takes no arguments beyond those in its usage line.
