`biomcp help get pathway` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It read pathway genes and source events. This page lists its reply.

The program's help describes it:

> Read pathway genes and source events.

## Usage

```text
biomcp help get pathway
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
