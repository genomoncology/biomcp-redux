`biomcp help serve` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It serve MCP over standard input or HTTP. This page lists its reply.

The program's help describes it:

> Serve MCP over standard input or HTTP.

## Usage

```text
biomcp help serve
```

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
