`biomcp skill` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It shows the agent guide and worked examples built into BioMCP. This page lists its usage.

The program's help describes it:

> Read embedded guidance and worked examples. No source requests. Overview and catalog are bounded by the embedded payload; install and status return one summary. Install writes only inside DIR and refuses symbolic links and parent traversal.

## Usage

```text
biomcp skill
```

## Arguments

The command takes no arguments beyond those in its usage line.
