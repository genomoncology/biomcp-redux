`biomcp help search protein` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It read protein sequences, features and source relationships. This page lists its reply.

The program's help describes it:

> Read protein sequences, features and source relationships.

## Usage

```text
biomcp help search protein
```

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
