`biomcp help article recommendations` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It describe help article recommendations. This page lists its reply.

The program's help describes it:

> Describe help article recommendations.

## Usage

```text
biomcp help article recommendations
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
