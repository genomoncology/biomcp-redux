`biomcp help health` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It report source terms and bounded reachability. This page lists its reply.

The program's help describes it:

> Report source terms and bounded reachability.

## Usage

```text
biomcp help health
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
