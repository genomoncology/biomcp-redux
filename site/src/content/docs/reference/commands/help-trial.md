`biomcp help trial` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It read trial groups and public documents. This page lists its reply.

The program's help describes it:

> Read trial groups and public documents.

## Usage

```text
biomcp help trial
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
