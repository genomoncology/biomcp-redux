`biomcp help search author` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It read papers attributed to a source author record. This page lists its reply.

The program's help describes it:

> Read papers attributed to a source author record.

## Usage

```text
biomcp help search author
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
