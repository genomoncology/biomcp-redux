`biomcp help search` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It search source records by [entity](/concepts/progressive-disclosure/) and checked filters. This page lists its reply.

The program's help describes it:

> Search source records by entity and checked filters.

## Usage

```text
biomcp help search
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
