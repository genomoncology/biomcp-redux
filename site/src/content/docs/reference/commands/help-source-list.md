`biomcp help source list` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It list supported discovery topics. This page lists its reply.

The program's help describes it:

> List supported discovery topics.

## Usage

```text
biomcp help source list
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
