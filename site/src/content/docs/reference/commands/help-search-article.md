`biomcp help search article` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It read article text, references, citations and files. This page lists its reply.

The program's help describes it:

> Read article text, references, citations and files.

## Usage

```text
biomcp help search article
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
