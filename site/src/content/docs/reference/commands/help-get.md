`biomcp help get` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It retrieve one [entity](/concepts/progressive-disclosure/) and its source sections. This page lists its reply.

The program's help describes it:

> Retrieve one entity and its source sections.

## Usage

```text
biomcp help get
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
