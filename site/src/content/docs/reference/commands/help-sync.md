`biomcp help sync` is a command of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. It synchronize a local source [bundle](/local-data/). This page lists its reply.

The program's help describes it:

> Synchronize a local source bundle.

## Usage

```text
biomcp help sync
```

## Reply

The reply is one JSON object. Its schema is [`biomcp.help/6`](/reference/schemas/biomcp-help-6/), whose page lists its fields.
