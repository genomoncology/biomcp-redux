This site documents BioMCP <Fact k="version" /> only. The BioMCP 0.9 documentation is kept as Markdown in the repository, under `docs/` at the `v0.9.3` tag: [BioMCP 0.9.3 documentation on GitHub](https://github.com/genomoncology/biomcp/tree/v0.9.3/docs).

## Which version you run

`biomcp version` prints it. Commands, options, output and the MCP tools differ between 0.9 and 1.0, so read the 0.9 pages for a 0.9 install and this site for a 1.0 install.

## Old addresses

An address from the 0.9 site redirects to the 1.0 page on the same topic. A 0.9 command has no page of its own here; the [Command map from 0.9 to 1.0](/reference/upgrade-map/) gives each 0.9 command's outcome in 1.0.
