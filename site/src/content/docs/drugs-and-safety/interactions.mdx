BioMCP <Fact k="version" /> is a command line tool and MCP server for biomedical data from public sources. It reads drug-drug interactions from DDInter, a local [bundle](/local-data/), with the `interactions` section of `get drug --source ddinter`. The example is vemurafenib, DDInter's `DDInter1925`.

## Requirements

- BioMCP installed. No key is needed.
- The DDInter bundle: run `biomcp sync ddinter` once. Before the sync the reply is `failed`, the source's state is `syncing`, the exit code is 4, and `next` names the sync. [Local data](/local-data/#bundle-sizes) shows its size.

## Limits

The level is DDInter's own rating of each pair. BioMCP returns it as DDInter publishes it and does not judge whether an interaction matters for anyone.
