Daraxonrasib is a RAS(ON) inhibitor from Revolution Medicines, and it reached the FDA this year. This tutorial follows it through BioMCP <Fact k="version" />, a command line tool and MCP server for biomedical data from public sources, in seven steps over two parts. This part, steps 1 to 3, gives its identifiers, its FDA application and its label. [Part 2](/blog/daraxonrasib-trials-and-reports/) finds its papers, trials, one trial's eligibility text and the adverse event count. Each step names the source that answered.

This page collects records. It does not say who should take the drug, and it reads no one's case.

## Before you start

- BioMCP installed; see [install](/getting-started/installation/).
- A network that reaches MyChem.info, Drugs@FDA and openFDA. No key is needed.
- `jq`, to trim each reply to the fields shown.

## 1. Find the drug's identity

The default drug source is MyChem.info, which merges several databases:

<Example id="blog-dara-identity" />

The `sources` list names every database that contributed. The `id` is MyChem.info's key, an InChIKey. It is not an FDA identifier, so the next step asks the FDA source directly.

## 2. Read the FDA application

`--source drugsfda` searches Drugs@FDA. The application number leads to its approval history:

<Example id="blog-dara-fda" />

Drugs@FDA lists application NDA220910 for RASONQUE tablets, with an original approval (`AP`, `ORIG`) dated 2026-08-26 under priority review. The submission class and the orphan code are Drugs@FDA's own fields. The [FDA approval date answer](/answers/fda-approval-date/) shows the same steps for vemurafenib.

**Checkpoint.** The approvals row has status `AP`. A different row means the source changed since this run.

## 3. Read the label

The openFDA label source knows the drug by its brand name:

<Example id="blog-dara-label" />

The search for `daraxonrasib` is `absent`, and the search for `RASONQUE` finds the label. Each source matches names its own way, so an empty reply describes one source and one spelling. The last lines are the label's own first sentence under its indications heading, wrapped at 80 characters by `fold`, as openFDA serves it. BioMCP returns label text unchanged and does not summarize it.
