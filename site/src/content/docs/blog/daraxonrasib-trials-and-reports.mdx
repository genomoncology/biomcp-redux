Daraxonrasib is a RAS(ON) inhibitor from Revolution Medicines, and it reached the FDA this year. This tutorial follows it through BioMCP <Fact k="version" />, a command line tool and MCP server for biomedical data from public sources. [Part 1](/blog/daraxonrasib-six-commands/) found its identifiers, its FDA application NDA220910 and its RASONQUE label. This part finds its trial reports, its registered trials, the eligibility text of one trial, and the adverse event count. Each step names the source that answered.

This page collects records. It does not say who should take the drug, and it reads no one's case.

## Before you start

- BioMCP installed; see [install](/getting-started/installation/).
- A network that reaches PubMed, ClinicalTrials.gov and openFDA. No key is needed.
- `jq`, to trim each reply to the fields shown.

## 4. Find the papers

`--drug` searches PubMed by drug name. `--type randomized` keeps randomized trial reports:

<Example id="blog-dara-articles" />

The first search mixes the discovery paper with later studies, and its rows change as PubMed adds papers. The filtered search finds the randomized trial report in the New England Journal of Medicine, and `get article` returns its DOI and publication date. [Read an article's full text](/how-to/find-articles/read-full-text/) shows how to read it when an article is open access.

## 5. List the registered trials

`--intervention` searches ClinicalTrials.gov interventions:

<Example id="blog-dara-trials" lines={9} />

ClinicalTrials.gov returns 15 studies that list daraxonrasib, from first-in-human combinations to phase 3 trials and an expanded access program. The status column is the registry's. A combination study run by another sponsor appears here because it lists daraxonrasib as an intervention; read each record before you count it.

## 6. Read one trial's eligibility text

NCT06625320 is the phase 3 study in previously treated pancreatic cancer, and its status is `ACTIVE_NOT_RECRUITING`. The `eligibility` section returns the registry's criteria unchanged. This filter keeps the lines that mention RAS:

<Example id="blog-dara-eligibility" />

The criteria define RAS mutations by codon: G12, G13 or Q61 in KRAS, NRAS or HRAS. That definition is the trial's, written for its own enrollment. BioMCP does not match a person to a trial; the whole record governs enrollment, and [Find clinical trials by condition, gene or variant](/how-to/find-trials/#make-a-screen-complete) lists what a complete screen needs.

## 7. Count adverse event reports

FAERS holds spontaneous reports to the FDA. Search it under both names:

<Example id="blog-dara-faers" />

Both searches are `absent`, so the script exits with code 1. FAERS answered (`state` `ok`) and returned no report under either name. A new drug can have reports that FAERS has not yet published, so zero here is not a safety finding. [Search adverse event reports](/drugs-and-safety/adverse-events/) explains what report counts can and cannot show.
