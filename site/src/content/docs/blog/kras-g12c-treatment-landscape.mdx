KRAS G12C sits in at least five databases that matter: ClinVar, Drugs@FDA, ClinicalTrials.gov, PubMed and the variant aggregators. Each has its own identifiers and its own idea of a query. I first wrote this walk-through for BioMCP 0.9. BioMCP 1.0 changed the grammar, so here it is again with commands that ran when this page was built.

The goal is a researcher's map of the records, not advice about anyone's care. Every step says which source answered.

## 1. Pin the identity

Start from the gene and protein change. The search returns the identifiers other sources share, and the exact command for the next step:

That `next` command is the point. The agent never builds an HGVS string by hand. It copies one.

## 2. Read ClinVar

<Example id="blog-kras-clinvar" />

Three rows, three domains: germline pathogenicity, somatic clinical impact and oncogenicity. ClinVar keeps them separate, and so does BioMCP. Collapsing them into one word would lose exactly the context a reviewer needs.

## 3. Find the FDA applications

Drugs@FDA returns an application number for each of the two KRAS G12C inhibitors I searched:

<Example id="blog-kras-fda" />

From here, `get drug NDA214665 approvals --source drugsfda` gives the submission history, and the openFDA label search gives each label heading. The [drugs guide](/drugs-and-safety/) walks that path with vemurafenib.

## 4. Count trials two ways

Here is the step people skip. Search the variant text, then search the gene:

<Example id="blog-kras-trials" />

The gene search finds more recruiting trials than the variant search. Some name "KRAS mutation" without G12C. Some name the drug and not the variant. BioMCP sends your words to the registry as written, so the broader search is your job. The [clinical trials guide](/how-to/find-trials/#make-a-screen-complete) lists the steps for a complete screen.

## 5. Read the reviews

<Example id="blog-kras-reviews" />

`--type review` uses PubMed's own publication type. Add `--sort date` for the newest, or `--sort citations` for the most cited.

## 6. Keep the receipts

Every reply above carried a `sources` list: the source, its terms, its state. That is what makes the result checkable. When a source fails, the reply says so and BioMCP does not quietly ask another one. I would rather an agent report "ClinicalTrials.gov timed out" than hand me a list from somewhere else.

## What this does not do

It does not rank the drugs, judge which trial fits a patient, or read the eligibility criteria for you. It gets the records and keeps them traceable. That boundary is deliberate.

Try it yourself from the [quickstart](/getting-started/first-query/). The [variants guide](/how-to/annotate-variants/) shows the same steps for BRAF V600E.
