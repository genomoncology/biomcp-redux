BioMCP <Fact k="version" /> is one program with two faces. In the shell it is the `biomcp` command. In an agent it is an MCP server with <Fact k="counts.mcp_tools" /> tools: <Fact k="mcp_tools" />. It reaches genes, variants, trials, articles, drugs, diseases and <Fact k="counts.entities" /> entities in all, across <Fact k="counts.sources" /> public sources, and it says which source answered.

Each command sends its words and identifiers over the network to the public sources it names. Do not put names, record numbers or other identifying patient data in a query.

<TerminalHero id="home-trials" caption="A live ClinicalTrials.gov search, run when this site was built." />

## What it reaches

Each row is one capability guide. The entities are the nouns of the command line.

| Capability | Entities | First command |
| --- | --- | --- |
| [Search and read biomedical literature](/how-to/find-articles/) | article, author | `biomcp search article --gene BRAF --variant V600E` |
| [Find clinical trials by condition, gene or variant](/how-to/find-trials/) | trial | `biomcp search trial --condition melanoma` |
| [Look up a variant](/how-to/annotate-variants/) | variant | `biomcp search variant --gene BRAF --protein V600E` |
| [Genes and proteins](/genes-and-proteins/) | gene, protein, pathway | `biomcp get gene BRAF` |
| [Drugs and safety](/drugs-and-safety/) | drug, adverse-event, pgx, diagnostic | `biomcp search drug vemurafenib` |
| [Diseases and phenotypes](/diseases-and-phenotypes/) | disease, phenotype, gwas | `biomcp search disease melanoma` |
| [Studies and cell lines](/studies-and-cell-lines/) | study, cell-line | `biomcp get cell-line CVCL_0132` |

Every reply names its sources, their terms and whether each one answered. BioMCP retrieves records. It does not rank treatments, judge eligibility or make clinical decisions.
