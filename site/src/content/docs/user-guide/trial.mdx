BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `trial`. A registered clinical trial, read by NCT identifier from ClinicalTrials.gov, or from NCI with your key. BioMCP searches registry text. It makes no eligibility judgment.

## Commands

<CommandTable entity="trial" />

For ClinicalTrials.gov search pages, follow the returned `next` command unchanged. BioMCP checks `--next-page` and `--offset` against the retained search filters and the number of registry rows read. Local continuations require the original store. A hosted deployment can verify them across tasks with a shared continuation key. See [hosted paging setup](/getting-started/remote-http/#clinicaltrialsgov-paging-across-hosted-tasks).

If a continuation cannot be verified or the registry rejects it, run the suggested first-page restart in the CLI or with the `biomcp` CLI-argument tool over local stdio. With a typed entity tool or a hosted server, submit the original first-page search again. See [usage errors](/troubleshooting/usage-errors/#usagearguments-expected-a-supported-command-with-checked-arguments).

## Sections of get trial

`eligibility`, `outcomes`, `arms`, `locations`, `contacts`, `references`, `documents`, `all`, `diseases`, `summary`. The [get trial reference](/reference/commands/get-trial/) describes each one.
