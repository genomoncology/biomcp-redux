BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `trial`. A registered clinical trial, read by NCT identifier from ClinicalTrials.gov, or from NCI with your key. BioMCP searches registry text. It makes no eligibility judgment.

## Sections of get trial

`eligibility`, `outcomes`, `arms`, `locations`, `contacts`, `references`, `documents`, `all`, `diseases`, `summary`. The [get trial reference](/reference/commands/get-trial/) describes each one.
