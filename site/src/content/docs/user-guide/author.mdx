BioMCP <Fact k="version" /> entity `author`. An author record from Semantic Scholar or ORCID, and its papers. Author IDs identify provider records, not resolved people. Both sources are in the noncommercial use group.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp author papers`](/reference/commands/author-papers/) | One exact provider record's publication window. |
| [`biomcp search author`](/reference/commands/search-author/) | Literal author name query and native window; positional text maps to query. |
| [`biomcp get author`](/reference/commands/get-author/) | Exact qualified records in caller order, with no name reconciliation. |

## Sections of get author

none. The [get author reference](/reference/commands/get-author/) describes each one.

[semantic-scholar](/sources/semantic-scholar/), [orcid](/sources/orcid/).
