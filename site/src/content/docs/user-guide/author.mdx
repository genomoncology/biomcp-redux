BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `author`. An author record from Semantic Scholar or ORCID, and its papers. Author IDs identify source records, not resolved people. Both sources are in the noncommercial use group.
