BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `protein`. A reviewed human protein from UniProt, with InterPro domains and Complex Portal complexes. Each section also has a [relation command](/concepts/progressive-disclosure/), such as `biomcp protein domains P15056`, for paging.

## Sections of get protein

`features`, `domains`, `isoforms`, `complexes`, `structures`, `function`, `sequence`, `all`. The [get protein reference](/reference/commands/get-protein/) describes each one.

Exact feature and domain spans use zero-based, half-open coordinates `[start, end)`: the start is included and the end is excluded. For example, source residues 10 through 20 appear as `[9, 20)`. The `source_coordinates` field describes the original one-based inclusive convention. The `--position` selector also takes a one-based residue number. CLI Markdown and MCP text explain the convention when a reply contains spans.
