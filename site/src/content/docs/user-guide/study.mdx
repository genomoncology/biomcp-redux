BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `study`. A cBioPortal cancer study's metadata, read from a local bundle. Run `biomcp sync cbioportal-studies` first. BioMCP returns metadata and file references and computes no statistics.
