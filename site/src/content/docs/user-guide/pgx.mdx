BioMCP <Fact k="version" /> entity `pgx`. CPIC gene cards, recommendations, guidelines and diplotype lookups, and ClinPGx annotations, for a gene. BioMCP calculates no phenotype, activity score or dose.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp search pgx`](/reference/commands/search-pgx/) | Checked gene-keyed CPIC pair search. |
| [`biomcp get pgx`](/reference/commands/get-pgx/) | PGx card or section. |

## Sections of get pgx

`recommendations`, `guidelines`, `diplotype`, `annotations`. The [get pgx reference](/reference/commands/get-pgx/) describes each one.

## Sources

[cpic](/sources/cpic/), [clinpgx](/sources/pharmgkb/).
