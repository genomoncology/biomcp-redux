BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `pgx`. CPIC gene cards, recommendations, guidelines and diplotype lookups, and ClinPGx annotations, for a gene. BioMCP calculates no phenotype, activity score or dose.
