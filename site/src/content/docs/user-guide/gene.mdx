BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `gene`. A human gene, resolved against HGNC by symbol, alias, previous symbol or identifier. The card holds the HGNC identity, other identifiers, location, MANE transcript and the RefSeq summary.

## Sections of get gene

`protein`, `civic`, `clingen`, `constraint`, `expression`, `pathways`, `oncokb`, `all`. The [get gene reference](/reference/commands/get-gene/) describes each one.
