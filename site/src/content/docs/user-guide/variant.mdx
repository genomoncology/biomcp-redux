BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `variant`. A genomic variant, read by rsID, ClinGen allele ID, ClinVar Variation ID or reference-qualified HGVS. A variant search returns source candidates with their shared identifiers. No candidate becomes a chosen allele.
