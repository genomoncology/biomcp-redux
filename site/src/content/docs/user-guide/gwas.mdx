BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `gwas`. GWAS Catalog studies and associations, searched by variant, gene, trait, study or PubMed ID. Rows report published associations. They give no personal risk and name no causal gene.
