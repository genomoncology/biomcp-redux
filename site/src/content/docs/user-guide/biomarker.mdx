BioMCP <Fact k="version" /> searches biomarker concepts in [NCI](/sources/nci/) by name or synonym and reads a concept by its NCIt code. The source requires your own NCI key; [keys and configuration](/getting-started/api-keys/) explains how to set it.

## Commands

<CommandTable entity="biomarker" />

## Example

```sh
biomcp search biomarker --source nci --name PD-L1
biomcp get biomarker C96022 --source nci
```

## MCP calls

In typed mode, the `trial` tool offers `biomarker_search` and `biomarker_get`. Each call takes an object named after the action. The [MCP tools reference](/reference/mcp-server/#typed-entity-tools) lists the actions.
