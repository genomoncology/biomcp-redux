BioMCP <Fact k="version" />, the command-line tool and MCP server for biomedical data, groups its commands by [entity](/reference/entities/), the kind of record they read. This page covers `drug`. A drug as one source records it. Each source has its own identifier, so `get drug` takes `--source`. Identity cards never expand into sections on their own. Ask for each section by name.

<CommandTable entity="drug" />

## Sections of get drug

`xrefs`, `targets`, `indications`, `civic`, `label`, `approvals`, `regulatory`, `interactions`. The [get drug reference](/reference/commands/get-drug/) describes each one.

## Sources

[mychem](/sources/mychem/), [chembl](/sources/chembl/), [opentargets](/sources/opentargets/), [civic](/sources/civic/), [openfda-label](/sources/openfda/), [drugsfda](/sources/drugsfda/), [ema](/sources/ema/), [who-pq](/sources/who-prequalification/), [ddinter](/sources/ddinter/).

`ema`, `who-pq` and `ddinter` read local bundles. Run `biomcp sync ema`, `biomcp sync who-pq` or `biomcp sync ddinter` once before the first read; before the sync the source's state is `syncing` and the exit code is 4. [Local data](/local-data/) lists the bundle sizes.
