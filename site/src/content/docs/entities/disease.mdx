BioMCP <Fact k="version" /> entity `disease`. A disease term from MONDO, DOID or NCIt, or a SEER cancer site. Search resolves words to ontology terms. Get reads one exact identifier.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp search disease`](/reference/commands/search-disease/) | Literal discovery text or an explicit SEER catalog page. |
| [`biomcp get disease`](/reference/commands/get-disease/) | Exact concept or native SEER site with independently paged section. |

## Sections of get disease

`synonyms`, `xrefs`, `hierarchy`, `genes`, `phenotypes`, `incidence`, `survival`. The [get disease reference](/reference/commands/get-disease/) describes each one.

## Sources

[ols](/reference/sources/ols/), [mydisease](/reference/sources/mydisease/), [monarch](/reference/sources/monarch/), [seer](/reference/sources/seer/).
