BioMCP <Fact k="version" /> entity `adverse-event`. An adverse event report from FAERS or MAUDE, or a VAERS report summary from CDC WONDER. Report counts are reports, not people. They do not show that a product caused an event.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp search adverse-event`](/reference/commands/search-adverse-event/) | Search five report headers by default. |
| [`biomcp get adverse-event`](/reference/commands/get-adverse-event/) | Exact native report identity and an optional independently paged section. |

## Sections of get adverse-event

`drugs`, `reactions`, `unii`, `rxcui`, `product-ndc`, `package-ndc`, `spl-id`, `spl-set-id`, `application-number`, `devices`, `narrative`. The [get adverse-event reference](/reference/commands/get-adverse-event/) describes each one.
