BioMCP <Fact k="version" /> entity `phenotype`. A Human Phenotype Ontology term, with its disease and gene associations from the Monarch Initiative. Terms are terminology. Associations are the publisher's assertions, not diagnoses.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp search phenotype`](/reference/commands/search-phenotype/) | Search literal human HP term candidates through Monarch with bounded native pages. |
| [`biomcp get phenotype`](/reference/commands/get-phenotype/) | Read an exact HP term from HPO or Monarch, or page native source sections. |

## Sections of get phenotype

`synonyms`, `xrefs`, `hierarchy`, `diseases`, `genes`. The [get phenotype reference](/reference/commands/get-phenotype/) describes each one.

## Sources

[hpo](/reference/sources/hpo/), [monarch](/reference/sources/monarch/).
