BioMCP <Fact k="version" /> entity `study`. A cBioPortal cancer study's metadata, read from a local bundle. Run `biomcp sync cbioportal-studies` first. BioMCP returns metadata and file references and computes no statistics.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp search study`](/reference/commands/search-study/) | Literal stored metadata search; text is never parsed as a query language. |
| [`biomcp get study`](/reference/commands/get-study/) | Exact case-sensitive study card or bounded metadata section. |

## Sections of get study

`profiles`, `sample-lists`, `files`, `all`. The [get study reference](/reference/commands/get-study/) describes each one.
