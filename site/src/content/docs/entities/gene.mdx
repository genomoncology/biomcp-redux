BioMCP <Fact k="version" /> entity `gene`. A human gene, resolved against HGNC by symbol, alias, previous symbol or identifier. The card holds the HGNC identity, other identifiers, location, MANE transcript and the RefSeq summary.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp get gene`](/reference/commands/get-gene/) | Get one to twenty human gene inputs in their original order. |
| [`biomcp search gene`](/reference/commands/search-gene/) | Search genes by text, cytoband, or their intersection. |

## Sections of get gene

`protein`, `civic`, `clingen`, `constraint`, `expression`, `pathways`, `oncokb`, `all`. The [get gene reference](/reference/commands/get-gene/) describes each one.
