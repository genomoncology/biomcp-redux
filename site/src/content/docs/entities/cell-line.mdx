BioMCP <Fact k="version" /> entity `cell-line`. A cell line from Cellosaurus, with its ChEMBL record and assay count. An assay count is not a sensitivity measure.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp cell-line assay-count`](/reference/commands/cell-line-assay-count/) | A separate assay-count request, never implicit in metadata or all. |
| [`biomcp search cell-line`](/reference/commands/search-cell-line/) | One literal cell line search, with native order and no total claim. |
| [`biomcp get cell-line`](/reference/commands/get-cell-line/) | One exact identity and an optional bounded named section. |

## Sections of get cell-line

`names`, `identity`, `xrefs`, `variants`, `chembl`, `all`. The [get cell-line reference](/reference/commands/get-cell-line/) describes each one.

## Sources

[cellosaurus](/reference/sources/cellosaurus/), [chembl](/reference/sources/chembl/).
