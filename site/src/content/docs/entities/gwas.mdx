BioMCP <Fact k="version" /> entity `gwas`. GWAS Catalog studies and associations, searched by variant, gene, trait, study or PubMed ID. Rows report published associations. They give no personal risk and name no causal gene.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp get gwas`](/reference/commands/get-gwas/) | Source association or study and native context. |
| [`biomcp search gwas`](/reference/commands/search-gwas/) | Source associations in default p-value-ascending order. |

## Sections of get gwas

`loci`, `associations`, `ancestries`. The [get gwas reference](/reference/commands/get-gwas/) describes each one.
