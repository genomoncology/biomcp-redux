BioMCP <Fact k="version" /> entity `diagnostic`. A genetic test or diagnostic device from GTR, WHO prequalified diagnostics, the FDA companion diagnostics list, or an FDA PMA or 510(k) record. Choose the source with `--source`. A listing is not an authorization, and a companion row is not a treatment recommendation.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp search diagnostic`](/reference/commands/search-diagnostic/) | Search one diagnostic source. |
| [`biomcp get diagnostic`](/reference/commands/get-diagnostic/) | Get one exact source record or supported section. |

## Sections of get diagnostic

`genes`, `conditions`, `methods`, `regulatory`, `supplements`. The [get diagnostic reference](/reference/commands/get-diagnostic/) describes each one.

## Sources

[gtr](/reference/sources/gtr/), [who-ivd](/reference/sources/who-ivd/), [fda-cdx](/reference/sources/fda-cdx/), [fda-pma](/reference/sources/fda-pma/), [fda-510k](/reference/sources/fda-510k/).
