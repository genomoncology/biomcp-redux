BioMCP <Fact k="version" /> entity `drug`. A drug as one source records it. Each source has its own identifier, so `get drug` takes `--source`. Identity cards never expand into sections on their own. Ask for each section by name.

## Commands

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Literal single-source candidate discovery, without an implicit identity selection. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Exact native ID retrieval with an explicitly selected source. |

## Sections of get drug

`xrefs`, `targets`, `indications`, `civic`, `label`, `approvals`, `regulatory`, `interactions`. The [get drug reference](/reference/commands/get-drug/) describes each one.
