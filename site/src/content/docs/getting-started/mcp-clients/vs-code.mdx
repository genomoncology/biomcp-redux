BioMCP <Fact k="version" /> is a command line tool and MCP server for biomedical data from public sources. VS Code reads MCP servers from `.vscode/mcp.json` in the workspace, under a top-level `servers` key rather than the `mcpServers` key other clients use.

## Requirements

- BioMCP installed. See [install](/getting-started/installation/).
- VS Code with a chat that calls MCP tools.

## Print the entry

`--client vscode` (alias `servers`) prints the `servers` shape:

<Example id="mcp-config-vscode" />

The output above shows `/home/you/.local/bin/biomcp`; yours names your own path.

## Add it to the workspace

1. Create or open `.vscode/mcp.json` in the workspace.
2. Merge the `biomcp` entry into its `servers` object.
3. Start the server from VS Code, as the [VS Code MCP documentation](https://code.visualstudio.com/docs/copilot/chat/mcp-servers) describes.

## Verify

Ask the chat to "use biomcp to get gene BRAF". [Check that the server answers](/getting-started/mcp-clients/check-connection/) makes the same call from a shell.
