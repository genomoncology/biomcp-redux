BioMCP <Fact k="version" /> is a command line tool and MCP server for biomedical data from public sources. Claude Code can reach it two ways: the BioMCP plugin, which starts your installed `biomcp serve` and adds the BioMCP skill, or an MCP server entry you add yourself.

## Requirements

- Claude Code.
- BioMCP installed. See [install](/getting-started/installation/). The plugin starts the executable on your `PATH`; it does not install it.

## Install the plugin

In Claude Code, add the marketplace, then install the plugin:

The plugin registers the MCP server and installs the skill, which teaches Claude the command grammar and <Fact k="counts.use_cases" /> worked examples.

## Or add the server by hand

`claude mcp add biomcp -- PATH serve` registers the server, where `PATH` is the `command` path that `biomcp mcp-config` prints. That command is a fragment; this page shows no output for it. The [Claude Code MCP documentation](https://code.claude.com/docs/en/mcp) covers its scopes.

For a server that every user of one project gets, put the `mcpServers` entry in `.mcp.json` at the project root:

## Verify

Ask Claude Code to "use biomcp to get gene BRAF". It sends the command's words as the `args` array of the `biomcp` tool, and the tool returns the BRAF gene card. [Check that the server answers](/getting-started/mcp-clients/check-connection/) runs the same call from a shell.
