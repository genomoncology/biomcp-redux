BioMCP <Fact k="version" /> is a command line tool and MCP server for biomedical data from public sources. Besides its `biomcp` tool, the server offers `search` and `fetch`, two tools that follow the shape ChatGPT research clients expect. Both only read.

## Requirements

- BioMCP installed. See [install](/getting-started/installation/).
- For a remote client, an HTTP server it can reach. See [run as a server](/getting-started/remote-http/).

## Call search

`search` takes an [entity](/reference/entities/), the kind of record, and its arguments, such as `gene BRAF --limit 2`, or plain article text. This exchange starts the server over stdio and calls `search` the way a client does:

<Example id="mcp-search-tool" />

Each result has an `id` that `fetch` accepts, such as `gene HGNC:1097`. Rows without an exact record to fetch stay available through the `biomcp` tool.

## Connect a remote client

BioMCP ships no connection steps for ChatGPT, and none ran for this page. [OpenAI's MCP documentation](https://developers.openai.com/api/docs/mcp) says ChatGPT adds a custom MCP server by its remote URL. BioMCP's HTTP server does not authenticate callers, so a public URL needs a reverse proxy that does.
