BioMCP <Fact k="version" /> is a command line tool and MCP server for biomedical data from public sources. Codex registers MCP servers with its own `codex mcp add` command, so `biomcp mcp-config --client codex` prints that command, with your executable's path, in place of JSON.

## Requirements

- BioMCP installed. See [install](/getting-started/installation/).
- The Codex command line agent.

## Print the command

<Example id="mcp-config-codex" />

The output above shows `/home/you/.local/bin/biomcp`; yours names your own path.

## Run it

Run the printed line in a shell. Codex writes the server to `~/.codex/config.toml` under `[mcp_servers.biomcp]`, as the [Codex MCP documentation](https://learn.chatgpt.com/docs/extend/mcp?surface=cli) says. Start a new Codex session to load it.

## Verify

Ask Codex to "use biomcp to get gene BRAF". [Check that the server answers](/getting-started/mcp-clients/check-connection/) makes the same call from a shell.
