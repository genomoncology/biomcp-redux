This page installs BioMCP <Fact k="version" />. Every channel installs the same `biomcp` executable. Pick one channel, install, then check the version. Platforms: <Fact k="platforms" />.

## Requirements

- A shell with `curl` or `wget` and a SHA-256 tool (`sha256sum`, `shasum` or `openssl`) for the installer script.
- Python <Fact k="python" /> or later for the PyPI package.
- No account and no key. Some sources take an optional key later; see [keys and configuration](/getting-started/api-keys/).

## Install with the script

<InstallLine />

The script downloads the release archive for your platform, downloads its checksum, verifies it, and installs `biomcp` into `~/.local/bin`. It refuses to install when the checksum does not match. Set `BIOMCP_INSTALL_DIR` to install somewhere else. Pin a release with `--version`:

<InstallLine k="install.script_version" />

On Windows, run the script from an MSYS, MINGW or Cygwin shell. It installs `biomcp.exe` from the ZIP archive.

## Install the desktop extension or the Claude Code plugin

The `.mcpb` desktop extension packs the executable and starts it with `serve`. Each release has one `.mcpb` for macOS on x86_64, one for macOS on arm64 and one for Windows on x86_64. There is no Linux `.mcpb`: on Linux, install with a line above and add `biomcp serve` to your client with `biomcp mcp-config`. The Claude Code plugin starts an installed `biomcp serve` and adds the BioMCP skill. Both are covered on [connect an agent](/getting-started/mcp-clients/).

## Check the install

<Example id="version" />

The version line is the success check. `biomcp version --verbose` adds the commit, the target platform, the schema versions and the paths of the configuration file and the cache.

## If the command is not found

The installer script puts `biomcp` in `~/.local/bin`. When your shell says `command not found`, that folder is not on your `PATH`. Add it in your shell profile, for example `export PATH="$HOME/.local/bin:$PATH"`, and open a new shell. For other failures, see [troubleshooting](/troubleshooting/).

## Upgrade and remove

BioMCP has no self-update command. Upgrade and remove it with the channel that installed it: rerun the installer script, `uv tool upgrade biomcp-cli`, `brew upgrade biomcp`, or pull a newer image. Coming from 0.9? Read [upgrading from 0.9](/upgrade-from-0-9/).
