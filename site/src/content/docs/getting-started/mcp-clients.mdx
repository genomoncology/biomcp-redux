BioMCP <Fact k="version" /> runs as an MCP server with `biomcp serve`, so an AI client can call BioMCP commands as tools. Every client needs the same two things: the path of the installed `biomcp` executable and the word `serve`. Pick your client below; each page adds the server and confirms one tool call.

## Requirements

- BioMCP installed. See [install](/getting-started/installation/).
- An MCP client that starts stdio servers, or an agent that runs shell commands.

## Print the client configuration

`biomcp mcp-config` prints the configuration with the absolute path of the installed executable. Your output names your own path:

<span id="check-the-server-answers"></span><span id="if-the-client-shows-no-tools"></span>After you add the server, [check that the server answers](/getting-started/mcp-clients/check-connection/). That page also covers a client that shows no tools.

<span id="what-the-tool-can-change"></span>The `biomcp` tool is not read-only over stdio: it can download [bundles](/local-data/), local copies of sources, and clean the store. [What the MCP tool can change](/getting-started/mcp-clients/what-the-tool-can-change/) lists each command and what HTTP refuses.

<span id="run-the-server-over-http"></span>Clients that connect over HTTP use `biomcp serve --http`; [run as a server](/getting-started/remote-http/) covers addresses, allowed hosts and the health check.
