This page lists the changes in BioMCP <Fact k="version" />. The steps to move a 0.9 setup are on [upgrading from 0.9](/upgrade-from-0-9/), and every 0.9 command's outcome is in the [command map](/reference/upgrade-map/).

## Added

- One command grammar for <Fact k="counts.entities" /> entities: `search`, `get` with sections, and relation commands. `study` is an entity of its own.
- Typed `next` commands in every reply.
- `biomcp key set`, `key list` and `key remove`.
- `article pdf`, `article text` and `article supplement` with `--save`; `trial document` for posted trial PDFs.
- `variant normalize`, `variant population`, `variant recurrence` and `variant assertions`.
- Protein relation commands: features, domains, isoforms, complexes, complex members, structures and sequence. `pathway genes` and `pathway events`.
- Sources including HGNC, iCite, LitSense2, Cancer Hotspots, Mutalyzer, VariantValidator, OLS, InterPro, Complex Portal, WikiPathways, ORCID, HPO, the GWAS Catalog, the FDA companion diagnostics list, and openFDA PMA and 510(k). The [sources reference](/reference/sources/) lists all <Fact k="counts.sources" />.

## Changed

- JSON is the default output. `--format md` gives Markdown.
- The MCP server offers one `biomcp` tool plus `search` and `fetch`.
- `--source` is explicit and never falls back to another source.
- `X sync` became `sync X`; `serve-http` became `serve --http ADDR --allow-host HOST`; `cache clean` became `store clean`.
- One `config.json` holds format, disabled sources, proxy, CA bundle, HTTP hosts and keys. Every source is on by default.

## Removed

- `discover`, `search all`, `list`, every `chart` command, study analytics, `enrich`, `update`, `uninstall`, `mcp tools`, the `cache` utilities and `cvx sync`.
- KEGG, MedlinePlus, CVX, DGIdb, QuickGO, STRING and PharmacoDB data.
