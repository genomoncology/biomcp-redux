WikiPathways is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches WikiPathways and reads pathway members from a local [bundle](/local-data/). A [bundle](/local-data/) is a local copy of the source that `biomcp sync wikipathways` downloads. Replies name it `wikipathways`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `wikipathways` |
| Use group | `open` |
| Terms | CC0 1.0 waiver |
| Terms page | [https://www.wikipathways.org/help.html](https://www.wikipathways.org/help.html) |
| Key | None. |
| Local bundle | `biomcp sync wikipathways` |

## Commands

Pick this source with `--source wikipathways` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search pathway`](/reference/commands/search-pathway/) | Finds human pathways in Reactome, the default, or WikiPathways. |

These commands read WikiPathways as part of their reply. They do not take `--source wikipathways`:

| Command | Description |
| --- | --- |
| [`biomcp get pathway`](/reference/commands/get-pathway/) | Reads one Reactome or WikiPathways pathway, and optionally its summary, genes or events. |
| [`biomcp pathway genes`](/reference/commands/pathway-genes/) | Lists the genes and gene products of one pathway. |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync wikipathways`.

## Turn it off

Leave this source out of one command with `--disable-sources wikipathways`, or add `"wikipathways"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
