EMBL-EBI Ontology Lookup Service is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches MONDO, DOID and NCIt disease terms through OLS. It is the default disease source. Replies name it `ols`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `ols` |
| Use group | `attribution` |
| Terms | EMBL-EBI Terms of Use; ontology-specific rights |
| Terms page | [https://www.ebi.ac.uk/about/terms-of-use/](https://www.ebi.ac.uk/about/terms-of-use/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source ols` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search disease`](/reference/commands/search-disease/) | Finds disease concepts by text, or lists SEER cancer sites. |
| [`biomcp get disease`](/reference/commands/get-disease/) | Reads one disease concept or SEER cancer site, and optionally a section such as its genes or incidence. |

## Limits

Searches cover MONDO, DOID and NCIt. A term missing from these ontologies can exist elsewhere.

## Turn it off

Leave this source out of one command with `--disable-sources ols`, or add `"ols"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
