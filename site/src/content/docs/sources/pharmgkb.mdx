BioMCP 1.0.0 names this source `clinpgx`. BioMCP reads ClinPGx clinical, guideline and label annotations for a gene.

| Field | Value |
| --- | --- |
| Source name | `clinpgx` |
| Use group | `noncommercial` |
| Terms | ClinPGx data use policy; noncommercial access restriction; captured policy was a JavaScript shell |
| Terms page | [https://www.clinpgx.org/page/dataUsagePolicy](https://www.clinpgx.org/page/dataUsagePolicy) |
| Key | None. |

## Commands

Pick this source with `--source clinpgx` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp get pgx`](/reference/commands/get-pgx/) | PGx card or section. |

## Limits

Each annotation keeps ClinPGx's level of evidence. BioMCP does not rank or combine annotations.

## Turn it off

Leave this source out of one command with `--disable-sources clinpgx`, or add `"clinpgx"` to `disable_sources` in `config.json`. The group `noncommercial` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
