ClinGen Evidence Repository is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads ClinGen expert-panel variant assertions. Replies name it `erepo`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `erepo` |
| Use group | `restricted` |
| Terms | ClinGen sharing policy; record rights unverified |
| Terms page | [https://clinicalgenome.org/about/terms-of-use/](https://clinicalgenome.org/about/terms-of-use/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source erepo` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp variant assertions`](/reference/commands/variant-assertions/) | Lists the assertions one source, such as ClinVar, makes about a variant, a page at a time. |

These commands read ClinGen Evidence Repository as part of their reply. They do not take `--source erepo`:

| Command | Description |
| --- | --- |
| [`biomcp get variant`](/reference/commands/get-variant/) | Reads a variant by rsID, ClinVar ID, ClinGen allele ID or HGVS, and optionally sections such as ClinVar or population. |

## Limits

The example reads CA000434, the ClinGen allele ID of TP53 NM_000546.6:c.818G&gt;A (p.Arg273His). Only variants that a ClinGen expert panel classified have records. A missing record or an empty section describes this source for this input. It is not a negative finding.

## Turn it off

Leave this source out of one command with `--disable-sources erepo`, or add `"erepo"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
