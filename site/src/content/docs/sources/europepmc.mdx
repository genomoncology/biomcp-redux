Europe PMC is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches Europe PMC, including open full text and preprints, and resolves article identifiers. Replies name it `europepmc`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `europepmc` |
| Use group | `restricted` |
| Terms | Europe PMC copyright; record-specific licenses |
| Terms page | [https://europepmc.org/help#copyright](https://europepmc.org/help#copyright) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source europepmc` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search article`](/reference/commands/search-article/) | Finds articles by text, gene, disease, drug, variant, author, journal or date. |

These commands read Europe PMC as part of their reply. They do not take `--source europepmc`:

| Command | Description |
| --- | --- |
| [`biomcp get article`](/reference/commands/get-article/) | Reads one to twenty articles by PMID, PMCID or DOI, and optionally sections such as the full text. |

## Limits

Europe PMC includes preprints. Check each record's type before you cite it.

## Turn it off

Leave this source out of one command with `--disable-sources europepmc`, or add `"europepmc"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
