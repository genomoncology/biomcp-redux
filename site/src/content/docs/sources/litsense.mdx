LitSense2 is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP finds sentences that resemble the query text through LitSense2. Replies name it `litsense`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `litsense` |
| Use group | `restricted` |
| Terms | NCBI policies; publisher rights in input text |
| Terms page | [https://www.ncbi.nlm.nih.gov/home/about/policies/](https://www.ncbi.nlm.nih.gov/home/about/policies/) |
| Key | None. |

## Commands

Pick this source with `--source litsense` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search article`](/reference/commands/search-article/) | Finds articles by text, gene, disease, drug, variant, author, journal or date. |

## Limits

LitSense2 returns sentences that resemble the query. A similar sentence is not a confirmed finding.

## Turn it off

Leave this source out of one command with `--disable-sources litsense`, or add `"litsense"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
