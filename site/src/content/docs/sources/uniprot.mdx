UniProt is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads reviewed human protein records, features, isoforms, function text and sequences from UniProt. Replies name it `uniprot`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `uniprot` |
| Use group | `attribution` |
| Terms | CC BY 4.0 |
| Terms page | [https://www.uniprot.org/help/license](https://www.uniprot.org/help/license) |
| Key | None. |

## Commands

These commands read UniProt as part of their reply. They do not take `--source uniprot`:

| Command | Description |
| --- | --- |
| [`biomcp search protein`](/reference/commands/search-protein/) | Finds reviewed human UniProt proteins by text or by gene, five at a time. |
| [`biomcp get protein`](/reference/commands/get-protein/) | Reads UniProt protein records by accession, and optionally sections such as domains or sequence. |
| [`biomcp protein features`](/reference/commands/protein-features/) | Lists UniProt features of one protein, five at a time, filtered by type or residue. |
| [`biomcp protein isoforms`](/reference/commands/protein-isoforms/) | Lists the isoforms of one protein, five at a time. |
| [`biomcp protein sequence`](/reference/commands/protein-sequence/) | Prints the whole amino-acid sequence of one UniProt protein or isoform. |
| [`biomcp protein structures`](/reference/commands/protein-structures/) | Lists the PDB structures of one protein, five at a time. |
| [`biomcp get gene`](/reference/commands/get-gene/) | Reads one to twenty human genes, in the order you give, and optionally sections such as constraint or expression. |

## Limits

BioMCP reads reviewed human entries. A missing record or an empty section describes this source for this input. It is not a negative finding.

## Turn it off

Leave this source out of one command with `--disable-sources uniprot`, or add `"uniprot"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
