CIViC is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads CIViC gene curation, variant molecular-profile evidence and drug therapy evidence. Replies name it `civic`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `civic` |
| Use group | `open` |
| Terms | CC0 1.0 |
| Terms page | [https://civicdb.org/releases/licensing](https://civicdb.org/releases/licensing) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source civic` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Finds drugs by name in one source. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Reads one drug record by its ID in one source, and optionally a section such as its label or approvals. |

These commands read CIViC as part of their reply. They do not take `--source civic`:

| Command | Description |
| --- | --- |
| [`biomcp get gene`](/reference/commands/get-gene/) | Reads one to twenty human genes, in the order you give, and optionally sections such as constraint or expression. |
| [`biomcp get variant`](/reference/commands/get-variant/) | Reads a variant by rsID, ClinVar ID, ClinGen allele ID or HGVS, and optionally sections such as ClinVar or population. |

## Limits

CIViC evidence is curated from publications and keeps its own evidence level. BioMCP does not rank it.

## Turn it off

Leave this source out of one command with `--disable-sources civic`, or add `"civic"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
