BioMCP 1.0.0 names this source `civic`. BioMCP reads CIViC gene curation, variant molecular-profile evidence and drug therapy evidence.

| Field | Value |
| --- | --- |
| Source name | `civic` |
| Use group | `open` |
| Terms | CC0 1.0 |
| Terms page | [https://civicdb.org/releases/licensing](https://civicdb.org/releases/licensing) |

## Commands

Pick this source with `--source civic` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Literal single-source candidate discovery, without an implicit identity selection. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Exact native ID retrieval with an explicitly selected source. |

These commands read CIViC as part of their reply. They do not take `--source civic`:

| Command | Description |
| --- | --- |
| [`biomcp get gene`](/reference/commands/get-gene/) | Get one to twenty human gene inputs in their original order. |
| [`biomcp get variant`](/reference/commands/get-variant/) | Read an rsID, CAid, ClinVar Variation ID or reference-qualified HGVS; chromosome notation requires --build. |

## Limits

CIViC evidence is curated from publications and keeps its own evidence level. BioMCP does not rank it.

## Turn it off

Leave this source out of one command with `--disable-sources civic`, or add `"civic"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
