ClinGen gene validity and dosage is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads ClinGen gene-disease validity and dosage curation from a local [bundle](/local-data/) that it can synchronize when a read needs it. A [bundle](/local-data/) is a local copy of the source that `biomcp sync clingen` downloads. Replies name it `clingen`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `clingen` |
| Use group | `open` |
| Terms | CC0 1.0 |
| Terms page | [https://clinicalgenome.org/docs/terms-of-use/](https://clinicalgenome.org/docs/terms-of-use/) |
| Key | None. |
| Local bundle | `biomcp sync clingen` |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

These commands read ClinGen gene validity and dosage as part of their reply. They do not take `--source clingen`:

| Command | Description |
| --- | --- |
| [`biomcp get gene`](/reference/commands/get-gene/) | Reads one to twenty human genes, in the order you give, and optionally sections such as constraint or expression. |

## Limits

BioMCP synchronizes the ClinGen bundle when a read needs it. Each classification keeps its expert panel and date.

## Turn it off

Leave this source out of one command with `--disable-sources clingen`, or add `"clingen"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
