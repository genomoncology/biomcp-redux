BioMCP 1.0.0 names this source `hpa`. BioMCP reads tissue expression for a gene from the Human Protein Atlas.

| Field | Value |
| --- | --- |
| Source name | `hpa` |
| Use group | `attribution` |
| Terms | CC BY 4.0; third-party conditions |
| Terms page | [https://www.proteinatlas.org/about/licence](https://www.proteinatlas.org/about/licence) |
| Key | None. |

## Commands

These commands read Human Protein Atlas as part of their reply. They do not take `--source hpa`:

| Command | Description |
| --- | --- |
| [`biomcp get gene`](/reference/commands/get-gene/) | Get one to twenty human gene inputs in their original order. |

## Limits

Expression categories are the Human Protein Atlas's own labels.

## Turn it off

Leave this source out of one command with `--disable-sources hpa`, or add `"hpa"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
