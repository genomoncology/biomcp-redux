Human Protein Atlas is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads tissue expression for a gene from the Human Protein Atlas. Replies name it `hpa`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `hpa` |
| Use group | `attribution` |
| Terms | CC BY 4.0; third-party conditions |
| Terms page | [https://www.proteinatlas.org/about/licence](https://www.proteinatlas.org/about/licence) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

These commands read Human Protein Atlas as part of their reply. They do not take `--source hpa`:

| Command | Description |
| --- | --- |
| [`biomcp get gene`](/reference/commands/get-gene/) | Reads one to twenty human genes, in the order you give, and optionally sections such as constraint or expression. |

## Limits

Expression categories are the Human Protein Atlas's own labels.

## Turn it off

Leave this source out of one command with `--disable-sources hpa`, or add `"hpa"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
