ClinicalTrials.gov is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches ClinicalTrials.gov and reads trial records, sections and posted documents. It is the default trial source. Replies name it `ctgov`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `ctgov` |
| Use group | `restricted` |
| Terms | ClinicalTrials.gov attribution and source processing date; publisher terms |
| Terms page | [https://clinicaltrials.gov/about-site/terms-conditions](https://clinicaltrials.gov/about-site/terms-conditions) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source ctgov` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search trial`](/reference/commands/search-trial/) | Finds clinical trials in ClinicalTrials.gov, the default, or NCI, by condition, drug, gene, location and more. |
| [`biomcp get trial`](/reference/commands/get-trial/) | Reads clinical trials by NCT ID, and optionally sections such as eligibility or locations. |

These commands read ClinicalTrials.gov as part of their reply. They do not take `--source ctgov`:

| Command | Description |
| --- | --- |
| [`biomcp trial document`](/reference/commands/trial-document/) | Downloads one document a trial posted on ClinicalTrials.gov, such as its protocol PDF, to a file you name. |

## Limits

Text filters such as `--variant` search registry text. They do not match a molecular profile. A listing is not an enrollment recommendation.

## Turn it off

Leave this source out of one command with `--disable-sources ctgov`, or add `"ctgov"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
