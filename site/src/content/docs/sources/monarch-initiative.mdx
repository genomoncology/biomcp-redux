Monarch Initiative is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads disease and phenotype associations with genes from the Monarch Initiative. Replies name it `monarch`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `monarch` |
| Use group | `attribution` |
| Terms | Monarch source-specific licensing |
| Terms page | [https://monarch-app.monarchinitiative.org/Licensing/](https://monarch-app.monarchinitiative.org/Licensing/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source monarch` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search phenotype`](/reference/commands/search-phenotype/) | Finds Human Phenotype Ontology (HP) terms by text in HPO or Monarch. |
| [`biomcp get phenotype`](/reference/commands/get-phenotype/) | Reads one HP term from HPO or Monarch, and optionally its synonyms, links, related diseases or genes. |
| [`biomcp search disease`](/reference/commands/search-disease/) | Finds disease concepts by text, or lists SEER cancer sites. |
| [`biomcp get disease`](/reference/commands/get-disease/) | Reads one disease concept or SEER cancer site, and optionally a section such as its genes or incidence. |

## Limits

Associations are Monarch's aggregation from its sources, each named in the association.

## Turn it off

Leave this source out of one command with `--disable-sources monarch`, or add `"monarch"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
