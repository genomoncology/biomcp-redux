MyDisease.info is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads disease records through MyDisease.info. `search trial --condition-id MONDO:0005105` looks the disease up here before the trial search runs. Replies name it `mydisease`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `mydisease` |
| Use group | `attribution` |
| Terms | MyDisease source-specific terms |
| Terms page | [https://docs.mydisease.info/en/latest/doc/data.html](https://docs.mydisease.info/en/latest/doc/data.html) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source mydisease` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search disease`](/reference/commands/search-disease/) | Finds disease concepts by text, or lists SEER cancer sites. |
| [`biomcp get disease`](/reference/commands/get-disease/) | Reads one disease concept or SEER cancer site, and optionally a section such as its genes or incidence. |

These commands read MyDisease.info as part of their reply. They do not take `--source mydisease`:

| Command | Description |
| --- | --- |
| [`biomcp search trial`](/reference/commands/search-trial/) | Finds clinical trials in ClinicalTrials.gov, the default, or NCI, by condition, drug, gene, location and more. |

## Limits

MyDisease.info aggregates other databases, each with its own terms.

## Turn it off

Leave this source out of one command with `--disable-sources mydisease`, or add `"mydisease"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
