BioMCP 1.0.0 names this source `cbioportal`. BioMCP reads cBioPortal study metadata from a local bundle and counts samples with a variant in one study.

| Field | Value |
| --- | --- |
| Source name | `cbioportal` |
| Use group | `restricted` |
| Terms | cBioPortal study-specific terms unverified; commercial restrictions may apply |
| Terms page | [https://docs.cbioportal.org/user-guide/faq/](https://docs.cbioportal.org/user-guide/faq/) |
| Key | None. |
| Local bundle | `biomcp sync cbioportal-studies` |

## Commands

Pick this source with `--source cbioportal` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp variant recurrence`](/reference/commands/variant-recurrence/) | Observe exact-allele samples within one caller-selected source page. |

These commands read cBioPortal as part of their reply. They do not take `--source cbioportal`:

| Command | Description |
| --- | --- |
| [`biomcp search study`](/reference/commands/search-study/) | Literal stored metadata search; text is never parsed as a query language. |
| [`biomcp get study`](/reference/commands/get-study/) | Exact case-sensitive study card or bounded metadata section. |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync cbioportal-studies`. Until the bundle exists, the source state is `syncing` and the reply names the sync command. BioMCP returns study metadata only and downloads no study data files.

## Turn it off

Leave this source out of one command with `--disable-sources cbioportal`, or add `"cbioportal"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
