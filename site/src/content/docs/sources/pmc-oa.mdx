PMC Open Access is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads licensed full text, supplements and PDFs from the PMC Open Access subset. Replies name it `pmc-oa`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `pmc-oa` |
| Use group | `restricted` |
| Terms | PMC copyright; article-specific licenses |
| Terms page | [https://pmc.ncbi.nlm.nih.gov/about/copyright/](https://pmc.ncbi.nlm.nih.gov/about/copyright/) |
| Key | None. |

## Commands

These commands read PMC Open Access as part of their reply. They do not take `--source pmc-oa`:

| Command | Description |
| --- | --- |
| [`biomcp get article`](/reference/commands/get-article/) | Reads one to twenty articles by PMID, PMCID or DOI, and optionally sections such as the full text. |
| [`biomcp article text`](/reference/commands/article-text/) | Reads one part of an article's full text, finds matching passages, or saves the text as Markdown. |
| [`biomcp article supplement`](/reference/commands/article-supplement/) | Reads one supplementary file of an article, or the rows of it that match a search, or saves the file. |
| [`biomcp article pdf`](/reference/commands/article-pdf/) | Downloads an article's PDF from its publisher to a file you name. |

## Limits

Only the PMC Open Access subset is read. Each article keeps its own license.

## Turn it off

Leave this source out of one command with `--disable-sources pmc-oa`, or add `"pmc-oa"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
