VariantValidator is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP sends reference-qualified HGVS to VariantValidator with a genome build. Replies name it `variantvalidator`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `variantvalidator` |
| Use group | `restricted` |
| Terms | VariantValidator service output terms require review |
| Terms page | [https://variantvalidator.org/help/about/](https://variantvalidator.org/help/about/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source variantvalidator` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp variant normalize`](/reference/commands/variant-normalize/) | Sends an HGVS variant name to the ClinGen Allele Registry, Mutalyzer or VariantValidator to check and normalize it. |

## Limits

VariantValidator needs `--build`. Keyless calls share a public rate limit and can return `rate_limited`.

## Turn it off

Leave this source out of one command with `--disable-sources variantvalidator`, or add `"variantvalidator"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
