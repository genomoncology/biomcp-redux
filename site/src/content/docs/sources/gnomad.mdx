gnomAD is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads gnomAD population counts for a variant and population constraint for a gene. Replies name it `gnomad`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `gnomad` |
| Use group | `open` |
| Terms | CC0 1.0 |
| Terms page | [https://gnomad.broadinstitute.org/policies](https://gnomad.broadinstitute.org/policies) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

These commands read gnomAD as part of their reply. They do not take `--source gnomad`:

| Command | Description |
| --- | --- |
| [`biomcp variant population`](/reference/commands/variant-population/) | Lists gnomAD population frequency details for one variant. |
| [`biomcp get variant`](/reference/commands/get-variant/) | Reads a variant by rsID, ClinVar ID, ClinGen allele ID or HGVS, and optionally sections such as ClinVar or population. |
| [`biomcp get gene`](/reference/commands/get-gene/) | Reads one to twenty human genes, in the order you give, and optionally sections such as constraint or expression. |

## Limits

A variant missing from gnomAD is not a zero frequency. Constraint values come from one gnomAD version, named in the reply.

## Turn it off

Leave this source out of one command with `--disable-sources gnomad`, or add `"gnomad"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
