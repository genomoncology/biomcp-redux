InterPro is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads InterPro domain and family matches for a protein. Replies name it `interpro`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `interpro` |
| Use group | `open` |
| Terms | CC0 |
| Terms page | [https://interpro-documentation.readthedocs.io/en/latest/license.html](https://interpro-documentation.readthedocs.io/en/latest/license.html) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

These commands read InterPro as part of their reply. They do not take `--source interpro`:

| Command | Description |
| --- | --- |
| [`biomcp protein domains`](/reference/commands/protein-domains/) | Lists the InterPro domains of one protein, five at a time. |
| [`biomcp get protein`](/reference/commands/get-protein/) | Reads UniProt protein records by accession, and optionally sections such as domains or sequence. |

## Limits

Matches come from InterPro's member databases as InterPro reports them.

## Turn it off

Leave this source out of one command with `--disable-sources interpro`, or add `"interpro"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
