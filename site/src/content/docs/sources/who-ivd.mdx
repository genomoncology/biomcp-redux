WHO prequalified in vitro diagnostics is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads WHO prequalified diagnostic products from a local copy of the WHO export. A [bundle](/local-data/) is a local copy of the source that `biomcp sync who-ivd` downloads. Replies name it `who-ivd`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `who-ivd` |
| Use group | `noncommercial` |
| Terms | WHO terms of use; export has no narrower license; commercial and substantial reproduction reserved |
| Terms page | [https://www.who.int/about/policies/terms-of-use](https://www.who.int/about/policies/terms-of-use) |
| Key | None. |
| Local bundle | `biomcp sync who-ivd` |

## Commands

Pick this source with `--source who-ivd` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search diagnostic`](/reference/commands/search-diagnostic/) | Finds diagnostic tests in one source, such as GTR, the FDA companion diagnostic list or WHO's prequalified tests. |
| [`biomcp get diagnostic`](/reference/commands/get-diagnostic/) | Reads one diagnostic test record, and optionally one section such as its genes or conditions. |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync who-ivd`. The list covers WHO prequalified products only.

## Turn it off

Leave this source out of one command with `--disable-sources who-ivd`, or add `"who-ivd"` to `disable_sources` in `config.json`. The group `noncommercial` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
