FDA MAUDE is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches and reads MAUDE medical device reports through openFDA. Replies name it `maude`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `maude` |
| Use group | `open` |
| Terms | openFDA terms and license; third-party exceptions |
| Terms page | [https://open.fda.gov/terms/](https://open.fda.gov/terms/) |
| Key | Optional; raises the rate limit. Set it with `biomcp key set openfda` or the environment variable `OPENFDA_API_KEY`. See [`help key openfda`](/reference/commands/help-key-openfda/). |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source maude` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search adverse-event`](/reference/commands/search-adverse-event/) | Finds adverse event reports in FAERS, VAERS or MAUDE, five at a time. |
| [`biomcp get adverse-event`](/reference/commands/get-adverse-event/) | Reads one adverse event report by its ID, and optionally one section such as its drugs or reactions. |

## Limits

A device report is the reporter's account. A report count is not a failure rate.

## Turn it off

Leave this source out of one command with `--disable-sources maude`, or add `"maude"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
