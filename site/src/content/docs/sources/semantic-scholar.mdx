Semantic Scholar is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches Semantic Scholar papers and authors and reads citations, references, recommendations and summaries. Replies name it `semantic-scholar`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `semantic-scholar` |
| Use group | `noncommercial` |
| Terms | Semantic Scholar API License Agreement |
| Terms page | [https://api.semanticscholar.org/license/](https://api.semanticscholar.org/license/) |
| Key | Optional; raises the rate limit. Set it with `biomcp key set semantic-scholar` or the environment variable `S2_API_KEY`. See [`help key semantic-scholar`](/reference/commands/help-key-semantic-scholar/). |

## Commands

Pick this source with `--source semantic-scholar` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search author`](/reference/commands/search-author/) | Finds author records by name in Semantic Scholar. |
| [`biomcp search article`](/reference/commands/search-article/) | Finds articles by text, gene, disease, drug, variant, author, journal or date. |
| [`biomcp article citations`](/reference/commands/article-citations/) | Lists the papers that cite one PubMed article, a page at a time. |
| [`biomcp article references`](/reference/commands/article-references/) | Lists the papers one PubMed article cites, a page at a time. |

These commands read Semantic Scholar as part of their reply. They do not take `--source semantic-scholar`:

| Command | Description |
| --- | --- |
| [`biomcp get author`](/reference/commands/get-author/) | Reads author records by their Semantic Scholar or ORCID ID, in the order you give. |
| [`biomcp author papers`](/reference/commands/author-papers/) | Lists the papers of one author record from Semantic Scholar or ORCID, a page at a time. |
| [`biomcp article citation-evidence`](/reference/commands/article-citation-evidence/) | Shows where and how one article cites another, with the citing passage when the full text is open. |
| [`biomcp article recommendations`](/reference/commands/article-recommendations/) | Lists papers that Semantic Scholar recommends from one or more seed papers. |
| [`biomcp get article`](/reference/commands/get-article/) | Reads one to twenty articles by PMID, PMCID or DOI, and optionally sections such as the full text. |

## Limits

Keyless calls share a public rate limit and can return `rate_limited`. A free key raises the limit.

## Turn it off

Leave this source out of one command with `--disable-sources semantic-scholar`, or add `"semantic-scholar"` to `disable_sources` in `config.json`. The group `noncommercial` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
