VAERS through CDC WONDER is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads VAERS report summaries for MMR, COVID-19 and named influenza vaccines from CDC WONDER. Replies name it `vaers`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `vaers` |
| Use group | `restricted` |
| Terms | CDC WONDER data use restrictions |
| Terms page | [https://wonder.cdc.gov/datause.html](https://wonder.cdc.gov/datause.html) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source vaers` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search adverse-event`](/reference/commands/search-adverse-event/) | Finds adverse event reports in FAERS, VAERS or MAUDE, five at a time. |

## Limits

VAERS reports are unverified, and a report does not show that a vaccine caused an event.

## Turn it off

Leave this source out of one command with `--disable-sources vaers`, or add `"vaers"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
