WHO prequalified finished products is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads WHO prequalified medicines from a local copy of the WHO export. A [bundle](/local-data/) is a local copy of the source that `biomcp sync who-pq` downloads. Replies name it `who-pq`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `who-pq` |
| Use group | `restricted` |
| Terms | WHO copyright policy; export-specific reuse grant unverified |
| Terms page | [https://www.who.int/about/policies/publishing/copyright](https://www.who.int/about/policies/publishing/copyright) |
| Key | None. |
| Local bundle | `biomcp sync who-pq` |

## Commands

Pick this source with `--source who-pq` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Finds drugs by name in one source. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Reads one drug record by its ID in one source, and optionally a section such as its label or approvals. |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync who-pq`. The list covers WHO prequalified finished products only.

## Turn it off

Leave this source out of one command with `--disable-sources who-pq`, or add `"who-pq"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
