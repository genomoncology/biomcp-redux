MyChem.info is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches drugs through MyChem.info. It is the default drug source. Replies name it `mychem`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `mychem` |
| Use group | `attribution` |
| Terms | BioThings and upstream source terms |
| Terms page | [https://docs.mychem.info/en/latest/doc/data_source.html](https://docs.mychem.info/en/latest/doc/data_source.html) |
| Key | None. |

## Example

## Commands

Pick this source with `--source mychem` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Finds drugs by name in one source. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Reads one drug record by its ID in one source, and optionally a section such as its label or approvals. |

## Limits

MyChem.info merges records from several databases, each named in `sources`.

## Turn it off

Leave this source out of one command with `--disable-sources mychem`, or add `"mychem"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
