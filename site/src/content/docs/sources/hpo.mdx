Human Phenotype Ontology is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches and reads HPO phenotype terms. Replies name it `hpo`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `hpo` |
| Use group | `attribution` |
| Terms | HPO project custom license: attribution, version and integrity |
| Terms page | [https://human-phenotype-ontology.github.io/license.html](https://human-phenotype-ontology.github.io/license.html) |
| Key | None. |

## Commands

Pick this source with `--source hpo` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search phenotype`](/reference/commands/search-phenotype/) | Finds Human Phenotype Ontology (HP) terms by text in HPO or Monarch. |
| [`biomcp get phenotype`](/reference/commands/get-phenotype/) | Reads one HP term from HPO or Monarch, and optionally its synonyms, links, related diseases or genes. |

## Limits

BioMCP reads HPO terms by identifier. Text search for phenotypes uses Monarch.

## Turn it off

Leave this source out of one command with `--disable-sources hpo`, or add `"hpo"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
