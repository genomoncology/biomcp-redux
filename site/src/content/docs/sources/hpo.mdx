BioMCP 1.0.0 names this source `hpo`. BioMCP searches and reads HPO phenotype terms.

| Field | Value |
| --- | --- |
| Source name | `hpo` |
| Use group | `attribution` |
| Terms | HPO project custom license: attribution, version and integrity |
| Terms page | [https://human-phenotype-ontology.github.io/license.html](https://human-phenotype-ontology.github.io/license.html) |

## Commands

Pick this source with `--source hpo` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search phenotype`](/reference/commands/search-phenotype/) | Search literal human HP term candidates through Monarch with bounded native pages. |
| [`biomcp get phenotype`](/reference/commands/get-phenotype/) | Read an exact HP term from HPO or Monarch, or page native source sections. |

## Limits

BioMCP reads HPO terms by identifier. Text search for phenotypes uses Monarch.

## Turn it off

Leave this source out of one command with `--disable-sources hpo`, or add `"hpo"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
