ClinVar is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads ClinVar assertions for a variant. Replies name it `clinvar`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `clinvar` |
| Use group | `restricted` |
| Terms | NCBI policy; submission rights remain source-specific |
| Terms page | [https://www.ncbi.nlm.nih.gov/clinvar/docs/maintenance_use/](https://www.ncbi.nlm.nih.gov/clinvar/docs/maintenance_use/) |
| Key | Optional; raises the rate limit. Set it with `biomcp key set ncbi` or the environment variable `NCBI_API_KEY`. See [`help key ncbi`](/reference/commands/help-key-ncbi/). |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source clinvar` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp variant assertions`](/reference/commands/variant-assertions/) | Lists the assertions one source, such as ClinVar, makes about a variant, a page at a time. |

These commands read ClinVar as part of their reply. They do not take `--source clinvar`:

| Command | Description |
| --- | --- |
| [`biomcp get variant`](/reference/commands/get-variant/) | Reads a variant by rsID, ClinVar ID, ClinGen allele ID or HGVS, and optionally sections such as ClinVar or population. |

## Limits

Each assertion keeps its submitter's classification. Conflicting classifications stay as ClinVar reports them.

## Turn it off

Leave this source out of one command with `--disable-sources clinvar`, or add `"clinvar"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
