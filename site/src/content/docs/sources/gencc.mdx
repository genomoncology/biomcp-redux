GenCC is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. Replies name it `gencc`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `gencc` |
| Use group | `open` |
| Terms | CC0 1.0 |
| Terms page | [https://thegencc.org/download](https://thegencc.org/download) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

```sh
biomcp --offline health | jq '.result.sources[] | select(.source == "gencc")'
```

## Commands

No command takes `--source gencc`. The example above shows the command that reads it.

## Limits

Check the publisher terms above and the source notices in each reply. Availability and returned content can change.

## Turn it off

Leave this source out of one command with `--disable-sources gencc`, or add `"gencc"` to `disable_sources` in `config.json`. The group `open` also excludes sources and fields with that category. See [keys and configuration](/getting-started/api-keys/).
