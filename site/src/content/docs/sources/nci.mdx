BioMCP 1.0.0 names this source `nci`. BioMCP searches the NCI Clinical Trials Search API and reads NCI trial records with your NCI key.

| Field | Value |
| --- | --- |
| Source name | `nci` |
| Use group | `restricted` |
| Terms | NCI Clinical Trials Search publisher terms; user's API key required |
| Terms page | [https://www.cancer.gov/syndication/api](https://www.cancer.gov/syndication/api) |
| Key | Required. Set it with `biomcp key set nci` or the environment variable `NCI_API_KEY`. See [`help key nci`](/reference/commands/help-key-nci/). |

## Commands

Pick this source with `--source nci` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search trial`](/reference/commands/search-trial/) | Search one provider with bounded pages and source-native counts; default ClinicalTrials.gov, explicit keyed NCI, never a fallback. |
| [`biomcp get trial`](/reference/commands/get-trial/) | Retrieve exact trial cards in input order; request bounded intact source sections with independent continuations. |

## Limits

NCI needs your own key. Without it BioMCP sends no request and reports `skipped` with reason `no_key`. BioMCP never falls back to ClinicalTrials.gov.

## Turn it off

Leave this source out of one command with `--disable-sources nci`, or add `"nci"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
