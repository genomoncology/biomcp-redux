FDA medical device recall is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. Replies name it `fda-device-recall`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `fda-device-recall` |
| Use group | `open` |
| Terms | openFDA terms and license; third-party exceptions |
| Terms page | [https://open.fda.gov/terms/](https://open.fda.gov/terms/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

```sh
biomcp --offline health | jq '.result.sources[] | select(.source == "fda-device-recall")'
```

## Commands

Pick this source with `--source fda-device-recall` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search diagnostic`](/reference/commands/search-diagnostic/) | Finds diagnostic tests in one source, such as GTR, the FDA companion diagnostic list or WHO's prequalified tests. |
| [`biomcp get diagnostic`](/reference/commands/get-diagnostic/) | Reads one diagnostic test record, and optionally one section such as its genes or conditions. |

## Limits

Check the publisher terms above and the source notices in each reply. Availability and returned content can change.

## Turn it off

Leave this source out of one command with `--disable-sources fda-device-recall`, or add `"fda-device-recall"` to `disable_sources` in `config.json`. The group `open` also excludes sources and fields with that category. See [keys and configuration](/getting-started/api-keys/).
