PubMed is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches PubMed and reads article citations, abstracts and MeSH indexing. It is the default article search source. Replies name it `pubmed`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `pubmed` |
| Use group | `restricted` |
| Terms | NCBI policies; publisher rights in abstracts |
| Terms page | [https://www.ncbi.nlm.nih.gov/home/about/policies/](https://www.ncbi.nlm.nih.gov/home/about/policies/) |
| Key | Optional; raises the rate limit. Set it with `biomcp key set ncbi` or the environment variable `NCBI_API_KEY`. See [`help key ncbi`](/reference/commands/help-key-ncbi/). |

## Commands

Pick this source with `--source pubmed` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search article`](/reference/commands/search-article/) | Finds articles by text, gene, disease, drug, variant, author, journal or date. |

These commands read PubMed as part of their reply. They do not take `--source pubmed`:

| Command | Description |
| --- | --- |
| [`biomcp get article`](/reference/commands/get-article/) | Reads one to twenty articles by PMID, PMCID or DOI, and optionally sections such as the full text. |

## Limits

A search returns what PubMed returned for those words. An empty search is not proof that no paper exists. Without a key, NCBI's public rate limit applies.

## Turn it off

Leave this source out of one command with `--disable-sources pubmed`, or add `"pubmed"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
