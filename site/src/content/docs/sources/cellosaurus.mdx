Cellosaurus is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads cell-line cards, names, identity, cross-references and variants from Cellosaurus. Replies name it `cellosaurus`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `cellosaurus` |
| Use group | `open` |
| Terms | Cellosaurus CC BY 4.0; cite Bairoch (2018) |
| Terms page | [https://www.cellosaurus.org/description.html](https://www.cellosaurus.org/description.html) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

These commands read Cellosaurus as part of their reply. They do not take `--source cellosaurus`:

| Command | Description |
| --- | --- |
| [`biomcp search cell-line`](/reference/commands/search-cell-line/) | Finds cell lines by name in Cellosaurus. |
| [`biomcp get cell-line`](/reference/commands/get-cell-line/) | Reads one cell line by its ID, and optionally one named section such as its variants. |

## Limits

Names stay as Cellosaurus writes them, so `A375` and `A-375` match different rows. A missing record or an empty section describes this source for this input. It is not a negative finding.

## Turn it off

Leave this source out of one command with `--disable-sources cellosaurus`, or add `"cellosaurus"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
