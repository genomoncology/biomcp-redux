BioMCP 1.0.0 names this source `cellosaurus`. BioMCP reads cell-line cards, names, identity, cross-references and variants from Cellosaurus.

## Commands

These commands read Cellosaurus as part of their reply. They do not take `--source cellosaurus`:

| Command | Description |
| --- | --- |
| [`biomcp search cell-line`](/reference/commands/search-cell-line/) | One literal cell line search, with native order and no total claim. |
| [`biomcp get cell-line`](/reference/commands/get-cell-line/) | One exact identity and an optional bounded named section. |

## Limits

Names stay as Cellosaurus writes them, so `A375` and `A-375` match different rows. A missing record or an empty section describes this source for this input. It is not a negative finding.

## Turn it off

Leave this source out of one command with `--disable-sources cellosaurus`, or add `"cellosaurus"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
