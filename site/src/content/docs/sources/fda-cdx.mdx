BioMCP 1.0.0 names this source `fda-cdx`. BioMCP reads the FDA list of cleared or approved companion diagnostic devices from a local bundle.

| Field | Value |
| --- | --- |
| Source name | `fda-cdx` |
| Use group | `open` |
| Terms | FDA website policies; third-party exceptions retained |
| Terms page | [https://www.fda.gov/about-fda/about-website/website-policies](https://www.fda.gov/about-fda/about-website/website-policies) |
| Key | None. |
| Local bundle | `biomcp sync fda-cdx` |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync fda-cdx`. Cells keep the FDA list's own text. `--biomarker` matches the whole biomarker cell of the device table, so a cell such as `KRAS and NRAS` does not match `KRAS`. The list's second table, of tests for a group of drugs, has no biomarker cell that `--biomarker` can read. So the search above returns `partial`: the source state is `ok` with reason `unsupported`, and `problems` names `table_1.biomarker`. Every row it returns is complete. [Find FDA companion diagnostics for a biomarker](/how-to/companion-diagnostics/#3-count-every-row-that-names-the-biomarker) counts every row that names a biomarker.

## Turn it off

Leave this source out of one command with `--disable-sources fda-cdx`, or add `"fda-cdx"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
