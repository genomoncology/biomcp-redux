NCBI Genetic Testing Registry is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads GTR test listings with their genes, conditions and methods from a local [bundle](/local-data/). A [bundle](/local-data/) is a local copy of the source that `biomcp sync gtr` downloads. Replies name it `gtr`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `gtr` |
| Use group | `open` |
| Terms | NCBI usage policies; submitter and third-party rights retained |
| Terms page | [https://www.ncbi.nlm.nih.gov/home/about/policies/](https://www.ncbi.nlm.nih.gov/home/about/policies/) |
| Key | None. |
| Local bundle | `biomcp sync gtr` |

## Commands

Pick this source with `--source gtr` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search diagnostic`](/reference/commands/search-diagnostic/) | Finds diagnostic tests in one source, such as GTR, the FDA companion diagnostic list or WHO's prequalified tests. |
| [`biomcp get diagnostic`](/reference/commands/get-diagnostic/) | Reads one diagnostic test record, and optionally one section such as its genes or conditions. |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync gtr`. A test listing is the laboratory's own registration, not a validation.

## Turn it off

Leave this source out of one command with `--disable-sources gtr`, or add `"gtr"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
