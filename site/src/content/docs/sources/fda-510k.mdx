openFDA 510(k) is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads one 510(k) clearance record. Replies name it `fda-510k`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `fda-510k` |
| Use group | `open` |
| Terms | openFDA terms and license; third-party exceptions |
| Terms page | [https://open.fda.gov/terms/](https://open.fda.gov/terms/) |
| Key | Optional; raises the rate limit. Set it with `biomcp key set openfda` or the environment variable `OPENFDA_API_KEY`. See [`help key openfda`](/reference/commands/help-key-openfda/). |

## Commands

Pick this source with `--source fda-510k` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp get diagnostic`](/reference/commands/get-diagnostic/) | Reads one diagnostic test record, and optionally one section such as its genes or conditions. |

## Limits

BioMCP reads one clearance by its K number. It does not search devices by name.

## Turn it off

Leave this source out of one command with `--disable-sources fda-510k`, or add `"fda-510k"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
