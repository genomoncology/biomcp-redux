Drugs@FDA is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads FDA application and product history for a drug. Replies name it `drugsfda`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `drugsfda` |
| Use group | `open` |
| Terms | openFDA terms; original label rights retained |
| Terms page | [https://open.fda.gov/terms/](https://open.fda.gov/terms/) |
| Key | Optional; raises the rate limit. Set it with `biomcp key set openfda` or the environment variable `OPENFDA_API_KEY`. See [`help key openfda`](/reference/commands/help-key-openfda/). |

## Commands

Pick this source with `--source drugsfda` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Finds drugs by name in one source. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Reads one drug record by its ID in one source, and optionally a section such as its label or approvals. |

## Limits

Drugs@FDA covers FDA applications and their products only. Label text comes from `openfda-label`, and European authorisations from `ema`.

## Turn it off

Leave this source out of one command with `--disable-sources drugsfda`, or add `"drugsfda"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
