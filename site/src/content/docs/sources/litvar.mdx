LitVar2 is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP finds publications that mention an exact variant through LitVar2. Replies name it `litvar`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `litvar` |
| Use group | `open` |
| Terms | NCBI public-domain metadata policy |
| Terms page | [https://www.ncbi.nlm.nih.gov/home/about/policies/](https://www.ncbi.nlm.nih.gov/home/about/policies/) |
| Key | None. |

## Commands

Pick this source with `--source litvar` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search article`](/reference/commands/search-article/) | Finds articles by text, gene, disease, drug, variant, author, journal or date. |

## Limits

LitVar2 matches exact variant identifiers. Other spellings of a variant can find other papers.

## Turn it off

Leave this source out of one command with `--disable-sources litvar`, or add `"litvar"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
