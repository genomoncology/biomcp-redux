Open Targets Platform is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads Open Targets drug records, targets and indications. Replies name it `opentargets`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `opentargets` |
| Use group | `open` |
| Terms | Open Targets CC0; underlying source provenance retained |
| Terms page | [https://platform-docs.opentargets.org/licence](https://platform-docs.opentargets.org/licence) |
| Key | None. |

## Commands

Pick this source with `--source opentargets` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Finds drugs by name in one source. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Reads one drug record by its ID in one source, and optionally a section such as its label or approvals. |

## Limits

Indications carry Open Targets' trial stage. A stage is not an approval.

## Turn it off

Leave this source out of one command with `--disable-sources opentargets`, or add `"opentargets"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
