BioMCP 1.0.0 names this source `opentargets`. BioMCP reads Open Targets drug records, targets and indications.

| Field | Value |
| --- | --- |
| Source name | `opentargets` |
| Use group | `open` |
| Terms | Open Targets CC0; underlying source provenance retained |
| Terms page | [https://platform-docs.opentargets.org/licence](https://platform-docs.opentargets.org/licence) |
| Key | None. |

## Commands

Pick this source with `--source opentargets` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Literal single-source candidate discovery, without an implicit identity selection. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Exact native ID retrieval with an explicitly selected source. |

## Limits

Indications carry Open Targets' trial stage. A stage is not an approval.

## Turn it off

Leave this source out of one command with `--disable-sources opentargets`, or add `"opentargets"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
