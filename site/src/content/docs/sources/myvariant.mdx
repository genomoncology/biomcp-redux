BioMCP 1.0.0 names this source `myvariant`. BioMCP searches variants and reads predictor, conservation and historical COSMIC fields through MyVariant.info.

| Field | Value |
| --- | --- |
| Source name | `myvariant` |
| Use group | `restricted` |
| Terms | MyVariant.info terms and component data licenses |
| Terms page | [https://myvariant.info/terms](https://myvariant.info/terms) |
| Key | None. |

## Commands

Pick this source with `--source myvariant` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search variant`](/reference/commands/search-variant/) | Discover source candidates using one declared selector, without interpreting free text. |

These commands read MyVariant.info as part of their reply. They do not take `--source myvariant`:

| Command | Description |
| --- | --- |
| [`biomcp get variant`](/reference/commands/get-variant/) | Read an rsID, CAid, ClinVar Variation ID or reference-qualified HGVS; chromosome notation requires --build. |

## Limits

MyVariant.info aggregates other databases, and its COSMIC fields are historical. Coordinates are GRCh37.

## Turn it off

Leave this source out of one command with `--disable-sources myvariant`, or add `"myvariant"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
