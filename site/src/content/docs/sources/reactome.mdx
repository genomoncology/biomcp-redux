Reactome is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches Reactome pathways and reads their genes and events, and the pathways section of a gene. Replies name it `reactome`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `reactome` |
| Use group | `open` |
| Terms | CC0 1.0 database data |
| Terms page | [https://reactome.org/license](https://reactome.org/license) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source reactome` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search pathway`](/reference/commands/search-pathway/) | Finds human pathways in Reactome, the default, or WikiPathways. |

These commands read Reactome as part of their reply. They do not take `--source reactome`:

| Command | Description |
| --- | --- |
| [`biomcp get pathway`](/reference/commands/get-pathway/) | Reads one Reactome or WikiPathways pathway, and optionally its summary, genes or events. |
| [`biomcp pathway genes`](/reference/commands/pathway-genes/) | Lists the genes and gene products of one pathway. |
| [`biomcp pathway events`](/reference/commands/pathway-events/) | Lists the events, such as reactions, of one Reactome pathway. |
| [`biomcp get gene`](/reference/commands/get-gene/) | Reads one to twenty human genes, in the order you give, and optionally sections such as constraint or expression. |

## Limits

Pathway membership is Reactome's curation. BioMCP runs no enrichment.

## Turn it off

Leave this source out of one command with `--disable-sources reactome`, or add `"reactome"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
