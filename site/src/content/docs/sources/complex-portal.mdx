Complex Portal is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads the protein complexes a protein takes part in and their members. Replies name it `complex-portal`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `complex-portal` |
| Use group | `open` |
| Terms | CC0 |
| Terms page | [https://pmc.ncbi.nlm.nih.gov/articles/PMC11701666/](https://pmc.ncbi.nlm.nih.gov/articles/PMC11701666/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

These commands read Complex Portal as part of their reply. They do not take `--source complex-portal`:

| Command | Description |
| --- | --- |
| [`biomcp protein complexes`](/reference/commands/protein-complexes/) | Lists the Complex Portal complexes that hold one protein, five at a time. |
| [`biomcp protein complex-members`](/reference/commands/protein-complex-members/) | Lists the members of one Complex Portal complex that holds the protein, five at a time. |
| [`biomcp get protein`](/reference/commands/get-protein/) | Reads UniProt protein records by accession, and optionally sections such as domains or sequence. |

## Limits

Complex Portal marks predicted complexes with `predicted`. Keep that flag with any claim.

## Turn it off

Leave this source out of one command with `--disable-sources complex-portal`, or add `"complex-portal"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
