CPIC is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads CPIC gene cards, recommendations, guidelines and diplotype lookups. Replies name it `cpic`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `cpic` |
| Use group | `noncommercial` |
| Terms | ClinPGx data use policy; noncommercial access restriction; captured policy was a JavaScript shell |
| Terms page | [https://www.clinpgx.org/page/dataUsagePolicy](https://www.clinpgx.org/page/dataUsagePolicy) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source cpic` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search pgx`](/reference/commands/search-pgx/) | Finds CPIC gene-drug pairs for a gene. |
| [`biomcp get pgx`](/reference/commands/get-pgx/) | Reads pharmacogenomic records from CPIC or ClinPGx, such as guidelines, recommendations or annotations. |

## Limits

BioMCP returns CPIC's published text and tables. It does not compute a phenotype or a dose from a genotype.

## Turn it off

Leave this source out of one command with `--disable-sources cpic`, or add `"cpic"` to `disable_sources` in `config.json`. The group `noncommercial` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
