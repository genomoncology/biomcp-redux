AlphaGenome is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP stores an AlphaGenome key with `biomcp key set alphagenome` or reads `ALPHAGENOME_API_KEY`. No command in this release sends a request to AlphaGenome. Replies name it `alphagenome`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `alphagenome` |
| Use group | `restricted` |
| Terms | AlphaGenome API terms |
| Terms page | [https://alphagenome.google/terms](https://alphagenome.google/terms) |
| Key | Required. Set it with `biomcp key set alphagenome` or the environment variable `ALPHAGENOME_API_KEY`. See [`help key alphagenome`](/reference/commands/help-key-alphagenome/). |

## Commands

No command takes `--source alphagenome`. The example above shows the command that reads it.

## Limits

AlphaGenome needs your own key and accepts its terms. The key help is the only output this release gives for AlphaGenome.

## Turn it off

Leave this source out of one command with `--disable-sources alphagenome`, or add `"alphagenome"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
