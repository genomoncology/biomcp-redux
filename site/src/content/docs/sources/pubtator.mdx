PubTator3 is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches PubTator3 [entities](/concepts/progressive-disclosure/) and reads text-mined annotations for an article. Replies name it `pubtator`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `pubtator` |
| Use group | `restricted` |
| Terms | NCBI policies; publisher rights in input text |
| Terms page | [https://www.ncbi.nlm.nih.gov/home/about/policies/](https://www.ncbi.nlm.nih.gov/home/about/policies/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source pubtator` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search article`](/reference/commands/search-article/) | Finds articles by text, gene, disease, drug, variant, author, journal or date. |

These commands read PubTator3 as part of their reply. They do not take `--source pubtator`:

| Command | Description |
| --- | --- |
| [`biomcp get article`](/reference/commands/get-article/) | Reads one to twenty articles by PMID, PMCID or DOI, and optionally sections such as the full text. |

## Limits

Annotations are text mining output and can be wrong.

## Turn it off

Leave this source out of one command with `--disable-sources pubtator`, or add `"pubtator"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
