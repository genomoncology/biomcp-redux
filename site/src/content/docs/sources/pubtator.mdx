BioMCP 1.0.0 names this source `pubtator`. BioMCP searches PubTator3 entities and reads text-mined annotations for an article.

| Field | Value |
| --- | --- |
| Source name | `pubtator` |
| Use group | `restricted` |
| Terms | NCBI policies; publisher rights in input text |
| Terms page | [https://www.ncbi.nlm.nih.gov/home/about/policies/](https://www.ncbi.nlm.nih.gov/home/about/policies/) |
| Key | None. |

## Commands

Pick this source with `--source pubtator` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search article`](/reference/commands/search-article/) | Checked search selectors and pool cursor. |

These commands read PubTator3 as part of their reply. They do not take `--source pubtator`:

| Command | Description |
| --- | --- |
| [`biomcp get article`](/reference/commands/get-article/) | Get one to twenty article inputs in caller order. |

## Limits

Annotations are text mining output and can be wrong.

## Turn it off

Leave this source out of one command with `--disable-sources pubtator`, or add `"pubtator"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
