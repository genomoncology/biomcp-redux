FDA drug recall is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. Replies name it `fda-drug-recall`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `fda-drug-recall` |
| Use group | `open` |
| Terms | openFDA terms and license; third-party exceptions |
| Terms page | [https://open.fda.gov/terms/](https://open.fda.gov/terms/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

```sh
biomcp --offline health | jq '.result.sources[] | select(.source == "fda-drug-recall")'
```

## Commands

Pick this source with `--source fda-drug-recall` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Finds drugs by name in one source. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Reads one drug record by its ID in one source, and optionally a section such as its label or approvals. |

## Limits

Check the publisher terms above and the source notices in each reply. Availability and returned content can change.

## Turn it off

Leave this source out of one command with `--disable-sources fda-drug-recall`, or add `"fda-drug-recall"` to `disable_sources` in `config.json`. The group `open` also excludes sources and fields with that category. See [keys and configuration](/getting-started/api-keys/).
