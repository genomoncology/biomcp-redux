SEER is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads SEER cancer sites, stage incidence and survival rows. Replies name it `seer`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `seer` |
| Use group | `open` |
| Terms | SEER/NCI Using This Website |
| Terms page | [https://seer.cancer.gov/about/using-website.html](https://seer.cancer.gov/about/using-website.html) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source seer` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search disease`](/reference/commands/search-disease/) | Finds disease concepts by text, or lists SEER cancer sites. |
| [`biomcp get disease`](/reference/commands/get-disease/) | Reads one disease concept or SEER cancer site, and optionally a section such as its genes or incidence. |

## Limits

SEER statistics describe the United States population that SEER covers. They are not a risk for one person.

## Turn it off

Leave this source out of one command with `--disable-sources seer`, or add `"seer"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
