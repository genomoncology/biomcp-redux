BioMCP 1.0.0 names this source `seer`. BioMCP reads SEER cancer sites, stage incidence and survival rows.

| Field | Value |
| --- | --- |
| Source name | `seer` |
| Use group | `open` |
| Terms | SEER/NCI Using This Website |
| Terms page | [https://seer.cancer.gov/about/using-website.html](https://seer.cancer.gov/about/using-website.html) |
| Key | None. |

## Commands

Pick this source with `--source seer` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search disease`](/reference/commands/search-disease/) | Literal discovery text or an explicit SEER catalog page. |
| [`biomcp get disease`](/reference/commands/get-disease/) | Exact concept or native SEER site with independently paged section. |

## Limits

SEER statistics describe the United States population that SEER covers. They are not a risk for one person.

## Turn it off

Leave this source out of one command with `--disable-sources seer`, or add `"seer"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
