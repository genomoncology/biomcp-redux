Mutalyzer is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP sends reference-qualified HGVS to Mutalyzer for normalization. Replies name it `mutalyzer`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `mutalyzer` |
| Use group | `restricted` |
| Terms | Mutalyzer service output terms require review |
| Terms page | [https://mutalyzer.nl/](https://mutalyzer.nl/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source mutalyzer` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp variant normalize`](/reference/commands/variant-normalize/) | Sends an HGVS variant name to the ClinGen Allele Registry, Mutalyzer or VariantValidator to check and normalize it. |

## Limits

Mutalyzer checks HGVS syntax against a reference sequence. It does not report clinical meaning.

## Turn it off

Leave this source out of one command with `--disable-sources mutalyzer`, or add `"mutalyzer"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
