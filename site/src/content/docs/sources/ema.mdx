European Medicines Agency is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads EMA medicine records and regulatory events from a local [bundle](/local-data/). A [bundle](/local-data/) is a local copy of the source that `biomcp sync ema` downloads. Replies name it `ema`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `ema` |
| Use group | `attribution` |
| Terms | EMA reproduction and attribution terms; third-party exceptions |
| Terms page | [https://www.ema.europa.eu/en/about-us/about-website/legal-notice](https://www.ema.europa.eu/en/about-us/about-website/legal-notice) |
| Key | None. |
| Local bundle | `biomcp sync ema` |

## Commands

Pick this source with `--source ema` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Finds drugs by name in one source. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Reads one drug record by its ID in one source, and optionally a section such as its label or approvals. |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync ema`. Records cover centrally authorised medicines.

## Turn it off

Leave this source out of one command with `--disable-sources ema`, or add `"ema"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
