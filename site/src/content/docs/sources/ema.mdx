BioMCP 1.0.0 names this source `ema`. BioMCP reads EMA medicine records and regulatory events from a local bundle.

| Field | Value |
| --- | --- |
| Source name | `ema` |
| Use group | `attribution` |
| Terms | EMA reproduction and attribution terms; third-party exceptions |
| Terms page | [https://www.ema.europa.eu/en/about-us/about-website/legal-notice](https://www.ema.europa.eu/en/about-us/about-website/legal-notice) |
| Key | None. |
| Local bundle | `biomcp sync ema` |

## Commands

Pick this source with `--source ema` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Literal single-source candidate discovery, without an implicit identity selection. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Exact native ID retrieval with an explicitly selected source. |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync ema`. Records cover centrally authorised medicines.

## Turn it off

Leave this source out of one command with `--disable-sources ema`, or add `"ema"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
