GWAS Catalog is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads GWAS Catalog studies, associations, loci and ancestries, and the gwas section of a variant. Replies name it `gwas`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `gwas` |
| Use group | `restricted` |
| Terms | GWAS Catalog terms and dataset rights |
| Terms page | [https://www.ebi.ac.uk/about/terms-of-use/](https://www.ebi.ac.uk/about/terms-of-use/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

These commands read GWAS Catalog as part of their reply. They do not take `--source gwas`:

| Command | Description |
| --- | --- |
| [`biomcp search gwas`](/reference/commands/search-gwas/) | Finds GWAS Catalog associations by trait, gene, variant, study or PubMed ID, smallest p-value first. |
| [`biomcp get gwas`](/reference/commands/get-gwas/) | Reads one GWAS Catalog association or study, and optionally its loci, associations or ancestries. |

## Limits

Broad searches, such as a search by gene, can exceed the request deadline. An association is the study's reported result, not a causal claim.

## Turn it off

Leave this source out of one command with `--disable-sources gwas`, or add `"gwas"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
