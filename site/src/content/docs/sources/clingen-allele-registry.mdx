ClinGen Allele Registry is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP resolves variant identities and normalizes HGVS through the ClinGen Allele Registry. Replies name it `car`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `car` |
| Use group | `restricted` |
| Terms | ClinGen Allele Registry service terms; output rights require review |
| Terms page | [https://clinicalgenome.org/about/terms-of-use/](https://clinicalgenome.org/about/terms-of-use/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source car` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp variant normalize`](/reference/commands/variant-normalize/) | Sends an HGVS variant name to the ClinGen Allele Registry, Mutalyzer or VariantValidator to check and normalize it. |

These commands read ClinGen Allele Registry as part of their reply. They do not take `--source car`:

| Command | Description |
| --- | --- |
| [`biomcp get variant`](/reference/commands/get-variant/) | Reads a variant by rsID, ClinVar ID, ClinGen allele ID or HGVS, and optionally sections such as ClinVar or population. |

## Limits

The Allele Registry needs a reference-qualified HGVS expression or an identifier it knows.

## Turn it off

Leave this source out of one command with `--disable-sources car`, or add `"car"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
