ChEMBL is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads ChEMBL drug targets and indications, and ChEMBL cell metadata and assay counts. Replies name it `chembl`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `chembl` |
| Use group | `attribution` |
| Terms | ChEMBL CC BY-SA 3.0 |
| Terms page | [https://chembl.github.io/chembl-licensing/](https://chembl.github.io/chembl-licensing/) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source chembl` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Finds drugs by name in one source. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Reads one drug record by its ID in one source, and optionally a section such as its label or approvals. |

These commands read ChEMBL as part of their reply. They do not take `--source chembl`:

| Command | Description |
| --- | --- |
| [`biomcp cell-line assay-count`](/reference/commands/cell-line-assay-count/) | Counts the ChEMBL assays recorded for one cell line. |
| [`biomcp get cell-line`](/reference/commands/get-cell-line/) | Reads one cell line by its ID, and optionally one named section such as its variants. |

## Limits

Targets and mechanisms are ChEMBL's curation. A target listing is not a measure of potency.

## Turn it off

Leave this source out of one command with `--disable-sources chembl`, or add `"chembl"` to `disable_sources` in `config.json`. The group `attribution` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
