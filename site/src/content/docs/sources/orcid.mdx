BioMCP 1.0.0 names this source `orcid`. BioMCP reads one ORCID record and its public works.

| Field | Value |
| --- | --- |
| Source name | `orcid` |
| Use group | `noncommercial` |
| Terms | ORCID Public API Terms of Service |
| Terms page | [https://info.orcid.org/public-client-terms-of-service/](https://info.orcid.org/public-client-terms-of-service/) |
| Key | Optional. Set it with `biomcp key set orcid` or the environment variable `ORCID_ACCESS_TOKEN`. See [`help key orcid`](/reference/commands/help-key-orcid/). |

## Commands

These commands read ORCID as part of their reply. They do not take `--source orcid`:

| Command | Description |
| --- | --- |
| [`biomcp get author`](/reference/commands/get-author/) | Exact qualified records in caller order, with no name reconciliation. |
| [`biomcp author papers`](/reference/commands/author-papers/) | One exact provider record's publication window. |

## Limits

BioMCP reads public ORCID records only. A record holds what its owner made public.

## Turn it off

Leave this source out of one command with `--disable-sources orcid`, or add `"orcid"` to `disable_sources` in `config.json`. The group `noncommercial` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
