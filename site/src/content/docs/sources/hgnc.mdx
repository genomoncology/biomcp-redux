BioMCP 1.0.0 names this source `hgnc`. BioMCP resolves gene symbols, aliases and identifiers against a local HGNC bundle that it can synchronize when a read needs it.

| Field | Value |
| --- | --- |
| Source name | `hgnc` |
| Use group | `open` |
| Terms | CC0 1.0 |
| Terms page | [https://www.genenames.org/about/license/](https://www.genenames.org/about/license/) |
| Key | None. |
| Local bundle | `biomcp sync hgnc` |

## Commands

These commands read HGNC as part of their reply. They do not take `--source hgnc`:

| Command | Description |
| --- | --- |
| [`biomcp search gene`](/reference/commands/search-gene/) | Search genes by text, cytoband, or their intersection. |
| [`biomcp get gene`](/reference/commands/get-gene/) | Get one to twenty human gene inputs in their original order. |

## Limits

BioMCP synchronizes the HGNC bundle when a read needs it. A missing record or an empty section describes this source for this input. It is not a negative finding.

## Turn it off

Leave this source out of one command with `--disable-sources hgnc`, or add `"hgnc"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
