HGNC is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP resolves gene symbols, aliases and identifiers against a local HGNC [bundle](/local-data/) that it can synchronize when a read needs it. A [bundle](/local-data/) is a local copy of the source that `biomcp sync hgnc` downloads. Replies name it `hgnc`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `hgnc` |
| Use group | `open` |
| Terms | CC0 1.0 |
| Terms page | [https://www.genenames.org/about/license/](https://www.genenames.org/about/license/) |
| Key | None. |
| Local bundle | `biomcp sync hgnc` |

## Commands

These commands read HGNC as part of their reply. They do not take `--source hgnc`:

| Command | Description |
| --- | --- |
| [`biomcp search gene`](/reference/commands/search-gene/) | Finds human genes by text, by cytoband, or both. |
| [`biomcp get gene`](/reference/commands/get-gene/) | Reads one to twenty human genes, in the order you give, and optionally sections such as constraint or expression. |

## Limits

BioMCP synchronizes the HGNC bundle when a read needs it. A missing record or an empty section describes this source for this input. It is not a negative finding.

## Turn it off

Leave this source out of one command with `--disable-sources hgnc`, or add `"hgnc"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
