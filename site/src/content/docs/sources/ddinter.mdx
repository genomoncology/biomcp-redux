BioMCP 1.0.0 names this source `ddinter`. BioMCP reads drug-drug interaction partners and levels from a local bundle.

| Field | Value |
| --- | --- |
| Source name | `ddinter` |
| Use group | `noncommercial` |
| Terms | DDInter CC BY-NC-SA 4.0 |
| Terms page | [https://ddinter.scbdd.com/terms/](https://ddinter.scbdd.com/terms/) |
| Key | None. |
| Local bundle | `biomcp sync ddinter` |

## Commands

Pick this source with `--source ddinter` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Literal single-source candidate discovery, without an implicit identity selection. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Exact native ID retrieval with an explicitly selected source. |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync ddinter`. An interaction level is DDInter's label, not advice for one patient.

## Turn it off

Leave this source out of one command with `--disable-sources ddinter`, or add `"ddinter"` to `disable_sources` in `config.json`. The group `noncommercial` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
