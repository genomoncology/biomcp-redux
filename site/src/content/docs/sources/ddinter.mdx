DDInter is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads drug-drug interaction partners and levels from a local [bundle](/local-data/). A [bundle](/local-data/) is a local copy of the source that `biomcp sync ddinter` downloads. Replies name it `ddinter`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `ddinter` |
| Use group | `noncommercial` |
| Terms | DDInter CC BY-NC-SA 4.0 |
| Terms page | [https://ddinter.scbdd.com/terms/](https://ddinter.scbdd.com/terms/) |
| Key | None. |
| Local bundle | `biomcp sync ddinter` |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source ddinter` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search drug`](/reference/commands/search-drug/) | Finds drugs by name in one source. |
| [`biomcp get drug`](/reference/commands/get-drug/) | Reads one drug record by its ID in one source, and optionally a section such as its label or approvals. |

## Limits

BioMCP reads a local copy, current as of your last `biomcp sync ddinter`. An interaction level is DDInter's label, not advice for one patient.

## Turn it off

Leave this source out of one command with `--disable-sources ddinter`, or add `"ddinter"` to `disable_sources` in `config.json`. The group `noncommercial` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
