NIH iCite is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads citation counts and citation links from NIH iCite. It is the default citation source. Replies name it `icite`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `icite` |
| Use group | `open` |
| Terms | NIH public-domain data |
| Terms page | [https://support.icite.nih.gov/hc/en-us/articles/9066501755291-Citations-Module-Overview](https://support.icite.nih.gov/hc/en-us/articles/9066501755291-Citations-Module-Overview) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

Pick this source with `--source icite` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp article citations`](/reference/commands/article-citations/) | Lists the papers that cite one PubMed article, a page at a time. |
| [`biomcp article references`](/reference/commands/article-references/) | Lists the papers one PubMed article cites, a page at a time. |

These commands read NIH iCite as part of their reply. They do not take `--source icite`:

| Command | Description |
| --- | --- |
| [`biomcp get article`](/reference/commands/get-article/) | Reads one to twenty articles by PMID, PMCID or DOI, and optionally sections such as the full text. |

## Limits

Citation counts change as NIH iCite updates. Record the date you read them.

## Turn it off

Leave this source out of one command with `--disable-sources icite`, or add `"icite"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
