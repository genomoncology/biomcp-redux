BioMCP 1.0.0 names this source `mygene`. BioMCP reads gene summaries through MyGene.info for the gene card.

| Field | Value |
| --- | --- |
| Source name | `mygene` |
| Use group | `restricted` |
| Terms | MyGene.info Terms of Use; upstream data terms |
| Terms page | [https://docs.mygene.info/en/latest/terms.html](https://docs.mygene.info/en/latest/terms.html) |
| Key | None. |

## Commands

These commands read MyGene.info as part of their reply. They do not take `--source mygene`:

| Command | Description |
| --- | --- |
| [`biomcp get gene`](/reference/commands/get-gene/) | Get one to twenty human gene inputs in their original order. |

## Limits

The gene summary is the RefSeq text with its date. BioMCP does not rewrite it.

## Turn it off

Leave this source out of one command with `--disable-sources mygene`, or add `"mygene"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
