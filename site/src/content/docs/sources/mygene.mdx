MyGene.info is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads gene summaries through MyGene.info for the gene card. Replies name it `mygene`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `mygene` |
| Use group | `restricted` |
| Terms | MyGene.info Terms of Use; upstream data terms |
| Terms page | [https://docs.mygene.info/en/latest/terms.html](https://docs.mygene.info/en/latest/terms.html) |
| Key | None. |

## Example

The command pipes the reply through `jq` to keep its `status`, the state of each source it asked, and a few fields of the result. Leave out the `jq` step to see the whole reply.

## Commands

These commands read MyGene.info as part of their reply. They do not take `--source mygene`:

| Command | Description |
| --- | --- |
| [`biomcp get gene`](/reference/commands/get-gene/) | Reads one to twenty human genes, in the order you give, and optionally sections such as constraint or expression. |

## Limits

The gene summary is the RefSeq text with its date. BioMCP does not rewrite it.

## Turn it off

Leave this source out of one command with `--disable-sources mygene`, or add `"mygene"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
