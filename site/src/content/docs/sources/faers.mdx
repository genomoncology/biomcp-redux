FDA Adverse Event Reporting System is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP searches and reads FAERS drug adverse event reports through openFDA. It is the default adverse event source. Replies name it `faers`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `faers` |
| Use group | `open` |
| Terms | openFDA terms and license; third-party exceptions |
| Terms page | [https://open.fda.gov/terms/](https://open.fda.gov/terms/) |
| Key | Optional; raises the rate limit. Set it with `biomcp key set openfda` or the environment variable `OPENFDA_API_KEY`. See [`help key openfda`](/reference/commands/help-key-openfda/). |

## Commands

Pick this source with `--source faers` on these commands:

| Command | Description |
| --- | --- |
| [`biomcp search adverse-event`](/reference/commands/search-adverse-event/) | Finds adverse event reports in FAERS, VAERS or MAUDE, five at a time. |
| [`biomcp get adverse-event`](/reference/commands/get-adverse-event/) | Reads one adverse event report by its ID, and optionally one section such as its drugs or reactions. |

## Limits

A report count is not an incidence rate. Reports are unverified and can be duplicated.

## Turn it off

Leave this source out of one command with `--disable-sources faers`, or add `"faers"` to `disable_sources` in `config.json`. The group `open` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
