OncoKB is one of the data sources of BioMCP 1.0.0, the command-line tool and MCP server that reads biomedical data sources. BioMCP reads OncoKB gene and variant annotations with your OncoKB key. Replies name it `oncokb`, and so do `--source` and `--disable-sources`.

| Field | Value |
| --- | --- |
| Source name | `oncokb` |
| Use group | `restricted` |
| Terms | OncoKB license |
| Terms page | [https://faq.oncokb.org/licensing](https://faq.oncokb.org/licensing) |
| Key | Required. Set it with `biomcp key set oncokb` or the environment variable `ONCOKB_TOKEN`. See [`help key oncokb`](/reference/commands/help-key-oncokb/). |

## Commands

These commands read OncoKB as part of their reply. They do not take `--source oncokb`:

| Command | Description |
| --- | --- |
| [`biomcp get gene`](/reference/commands/get-gene/) | Reads one to twenty human genes, in the order you give, and optionally sections such as constraint or expression. |
| [`biomcp get variant`](/reference/commands/get-variant/) | Reads a variant by rsID, ClinVar ID, ClinGen allele ID or HGVS, and optionally sections such as ClinVar or population. |

## Limits

OncoKB needs your own key and license. Without the key BioMCP sends no request and reports `skipped` with reason `no_key`.

## Turn it off

Leave this source out of one command with `--disable-sources oncokb`, or add `"oncokb"` to `disable_sources` in `config.json`. The group `restricted` switches off every source in that use group. See [keys and configuration](/getting-started/api-keys/).
