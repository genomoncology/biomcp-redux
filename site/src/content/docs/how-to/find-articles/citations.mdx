BioMCP <Fact k="version" /> is a command line tool and MCP server for biomedical data from public sources. `biomcp article citations` lists the papers that cite an article. NIH iCite is the default source; `--source semantic-scholar` uses Semantic Scholar's citation graph. The example is PMID 33123537, a review of AKT1 E17K.

## Requirements

- BioMCP installed. No key is needed. A Semantic Scholar key raises that source's rate limit; see [keys and configuration](/getting-started/api-keys/).

<Example id="lit-citations" />

The columns are the citing paper's PMID, its date and its title.

## Other directions

| Command | Returns |
| --- | --- |
| `article references ID` | the papers the article cites |
| `article citation-evidence ID` | the sentences where one paper cites another |
| `article recommendations ID` | similar papers, from Semantic Scholar |

## Limits

A citation count is the source's count. It does not measure a paper's quality.
