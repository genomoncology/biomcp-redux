BioMCP <Fact k="version" /> is a command line tool and MCP server for biomedical data from public sources. Add `--save PATH` to `article text`, `article supplement` or `article pdf` to write the file. `article text --save` writes the whole document, so it does not take `--part`.

## Requirements

- BioMCP installed. No key is needed.
- An open-access article in PMC; see [read an article's full text](/how-to/find-articles/read-full-text/).

## Rules

- On the command line, an existing file needs `--replace`.
- Over stdio MCP, a save writes a new file only, and `--replace` is refused.
- The HTTP server refuses every save; see [run as a server](/getting-started/remote-http/).

## Save and see the refusals

<Example id="lit-save-rules" />

The command line save and the first MCP save write the whole text, and each reply reports the bytes written. The `--part` save and the MCP `--replace` save are refused with status `usage`.
