BioMCP <Fact k="version" /> embeds <Fact k="counts.use_cases" /> worked examples in its agent skill. Each shows a command, what to read in its reply, and where the answer stops. They install with the skill (see [connect an agent](/getting-started/mcp-clients/#give-a-shell-agent-the-skill)) and print from the command line.

## Read one use case

`biomcp skill NAME` prints one example by its number and name:

## Limits

Each use case shows one starting command with a recorded reply. Several share a command and differ in what they tell the agent to read. They are starting points for a question type, not complete answers. Live replies change.
