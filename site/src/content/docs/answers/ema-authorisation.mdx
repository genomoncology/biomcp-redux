BioMCP 1.0.0 is a command-line tool and MCP server that reads biomedical data sources. Download EMA's medicines list once with `biomcp sync ema`, search the medicine with `--source ema`, then read its `regulatory` section. This BioMCP 1.0 run finds Zelboraf as EMEA/H/C/002409 and reports EMA's status and marketing authorisation date.

## Reading the output

| Field | In this run | Meaning |
| --- | --- | --- |
| `id` | `EMEA/H/C/002409` | The EMA product number, which `get drug` takes. |
| `status` | `Authorised` | The authorisation status that EMA reports. |
| `authorised` | `2012-02-17` | The marketing authorisation date, the row with role `marketing_authorisation_date`. |

## Why it works

EMA publishes its medicines table as a download. `biomcp sync ema` stores it, and reads answer from the stored copy. The `regulatory` section returns EMA's own status and dated events.

## Limits

The answer is as fresh as your last sync. Run `biomcp sync ema` again for current data. EMA's status covers the European Union only.
