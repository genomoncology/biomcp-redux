BioMCP 1.0.0 is a command-line tool and MCP server that reads biomedical data sources. Yes. BioMCP 1.0 is an MCP server whose `biomcp` tool runs `search article`, which searches PubMed by default. Add it to your client with the output of `biomcp mcp-config`, then call the tool with the command's words. This exchange starts the server over stdio and searches PubMed for KRAS G12C, as a client would.

## Reading the output

| Field | In this run | Meaning |
| --- | --- | --- |
| `pmid` | `37683526` | The PubMed ID of each article the `biomcp` tool returned. |
| `title` | `KRAS G12C in advanced NSCLC: Prevalence…` | The title, cut to 56 characters by the `cut` filter. |

## Why it works

`biomcp serve` speaks MCP over stdio. The `biomcp` tool takes an `args` array, the same words as the command line, and returns the same JSON reply. PubMed is the default `--source` for `search article`, so no source flag is needed. The same tool also reaches Europe PMC, PMC full text, iCite citations and Semantic Scholar.

## Limits

BioMCP sends your words to PubMed as written and returns PubMed's order. It does not summarize papers. Without an NCBI key PubMed applies its public rate limit; `biomcp key set ncbi` raises it.
