Request the gene's `protein` section: `biomcp get gene SYMBOL protein`. It returns the reviewed human UniProt entries for the gene. This BioMCP 1.0 run finds P15056 for BRAF, with its name and length.

## Why it works

BioMCP resolves the symbol against HGNC, then reads UniProt's reviewed human entries for that gene. The accession goes straight to `biomcp get protein P15056` for features, domains and sequence.

## Limits

Only reviewed (Swiss-Prot) human entries are returned. A gene with several reviewed products returns each one; BioMCP does not choose.
