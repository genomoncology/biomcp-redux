BioMCP 1.0.0 is a command-line tool and MCP server that reads biomedical data sources. Request the gene's `protein` section: `biomcp get gene SYMBOL protein`. It returns the reviewed human UniProt entries for the gene. This BioMCP 1.0 run finds P15056 for BRAF, with its name and length.

## Reading the output

| Field | In this run | Meaning |
| --- | --- | --- |
| `source` | `uniprot` | The source: `uniprot`. |
| `accession` | `P15056` | The UniProt accession of the reviewed human protein. |
| `name` | `Serine/threonine-protein kinase B-raf` | UniProt's recommended protein name. |
| `length` | `766` | The protein's length in amino acids. |

## Why it works

BioMCP resolves the symbol against HGNC, then reads UniProt's reviewed human entries for that gene. The accession goes straight to `biomcp get protein P15056` for features, domains and sequence.

## Limits

Only reviewed (Swiss-Prot) human entries are returned. A gene with several reviewed products returns each one; BioMCP does not choose.
