BioMCP 1.0.0 is a command-line tool and MCP server that reads biomedical data sources. Find the drug's FDA application in Drugs@FDA, then read its `approvals` section. The `ORIG` submission is the original application. This BioMCP 1.0 run sorts the history of NDA202429, the Zelboraf (vemurafenib) application, by date: its original approval is dated 2011-08-17.

## Reading the output

| Field | In this run | Meaning |
| --- | --- | --- |
| `total` | `16` | How many submissions Drugs@FDA lists for the application. |
| `kind` | `ORIG` | `ORIG` is the original application; `SUPPL` is a supplement. |
| `submission_number` | `1` | The submission's number within the application. |
| `status` | `AP` | `AP` means approved. |
| `date` | `2011-08-17` | The date of the action. The earliest `ORIG` row is the first approval. |

## Why it works

`biomcp search drug NAME --source drugsfda` returns the application number. The `approvals` section lists each submission with its kind, number, status and date as Drugs@FDA records them. `AP` means approved. `--section-limit` sets how many rows one page holds.

## Limits

Drugs@FDA covers FDA applications only. A drug with several applications, such as different forms, has a history for each. Dates are Drugs@FDA's submission status dates.
