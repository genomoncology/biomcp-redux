BioMCP 1.0.0 is a command-line tool and MCP server that reads biomedical data sources. Use `--intervention` with the drug name: `biomcp search trial --intervention sotorasib --status RECRUITING`. This BioMCP 1.0 run returns recruiting trials whose registered interventions or text match sotorasib.

## Reading the output

| Field | In this run | Meaning |
| --- | --- | --- |
| `nct_id` | `NCT06252649` | The trial's ClinicalTrials.gov identifier. |
| `title` | `Study of Sotorasib, Panitumumab and FOL…` | The registered title, cut to 56 characters by the `cut` filter. Read it to see the drug's role. |

## Why it works

`--intervention` sends literal text to the registry's intervention search. BioMCP adds no aliases, so search the brand name and code names too, such as an AMG number, when you need them.

## Limits

The registry decides what matches. A trial can mention the drug in another role, such as a diagnostic study about the same mutation. Read each record before reporting it.
