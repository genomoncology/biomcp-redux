BioMCP 1.0.0 is a command-line tool and MCP server that reads biomedical data sources. Run `biomcp get article PMID`. The article card holds the title, authors, journal, dates, publication types and the abstract as PubMed publishes it, in `abstract_parts`. This BioMCP 1.0 run prints the title and the start of the abstract for PMID 33123537.

## Reading the output

| Field | In this run | Meaning |
| --- | --- | --- |
| `title` | `Effect of AKT1 (p. E17K) Hotspot Mutati…` | The article title from PubMed, wrapped at 78 characters by `fold`. |
| `abstract` | `The substitution of the seventeenth ami…` | The first part of the abstract, as PubMed stores it. `head -8` keeps the first lines. |

## Why it works

`get article` resolves the identifier through PubMed and returns one card per input, in input order. The abstract stays in its source parts, so a structured abstract keeps its labels.

## Limits

The abstract is the publisher's text with its rights. Some PubMed records have no abstract. For the article body, request the `fulltext` section, which needs a PMC copy.
