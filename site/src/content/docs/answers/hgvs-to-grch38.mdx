Resolve the description with the ClinGen Allele Registry: `biomcp variant normalize --source car --hgvs 'NM_004985.5:c.35G>A'`. The reply maps the transcript change to its ClinGen allele ID and its GRCh38 genomic descriptions. KRAS c.35G>A, the change behind G12D, resolves to CA122538 and NC_000012.12:g.25245350C>T.

## Why it works

The registry stores each allele once and lists every description of it: transcripts, GRCh37 and GRCh38. BioMCP sends your text unchanged and returns the registry's mappings; it never edits the description to make it match.

## Limits

The description needs a versioned reference sequence, such as `NM_004985.5`. A description the registry cannot place returns an outcome other than `resolved`. `--source mutalyzer` and `--source variantvalidator` check the same description with other services.
