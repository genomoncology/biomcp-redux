BioMCP 1.0.0 is a command-line tool and MCP server that reads biomedical data sources. Request the gene's `constraint` section: `biomcp get gene SYMBOL constraint`. It returns gnomAD's loss-of-function constraint for the gene's canonical transcript. For TP53 this run returns gnomAD v4 values for transcript ENST00000269305, with pLI near 1 and LOEUF about 0.42.

## Reading the output

| Field | In this run | Meaning |
| --- | --- | --- |
| `source` | `gnomad` | The source: `gnomad`. |
| `version` | `v4` | The gnomAD release the values come from. |
| `transcript` | `ENST00000269305` | The transcript the constraint values describe. |
| `pli` | `0.999595868281925` | Probability of loss-of-function intolerance, from 0 to 1. |
| `loeuf` | `0.4183620979251529` | Loss-of-function observed/expected upper bound fraction. Lower values mean fewer loss-of-function variants than expected. |

## Why it works

BioMCP resolves the symbol against HGNC and reads gnomAD's constraint record for the gene. pLI is gnomAD's probability that the gene is intolerant of loss-of-function variants. LOEUF is the upper bound of the observed-to-expected ratio of loss-of-function variants; a lower value means fewer such variants than expected. The section also carries `oe_lof`, `mis_z` and `syn_z`.

## Limits

The scores describe variation in the people gnomAD sequenced, for one transcript and one gnomAD version. They are population statistics about the gene, not a classification of any variant.
