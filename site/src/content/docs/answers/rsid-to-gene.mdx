BioMCP 1.0.0 is a command-line tool and MCP server that reads biomedical data sources. Run `biomcp get variant RSID`. An rsID can name several alternate alleles, so BioMCP returns one candidate per allele, each with its gene, its other identifiers and its genomic HGVS. This BioMCP 1.0 run shows the three alleles MyVariant.info records for rs113488022 in BRAF.

## Reading the output

| Field | In this run | Meaning |
| --- | --- | --- |
| `ids` | `["rs113488022"]` | The identifiers of one candidate allele: the rsID, and a ClinVar ID when ClinVar has the allele. |
| `genes` | `["BRAF"]` | The gene the allele lies in. |
| `hgvs` | `["chr7:g.140453136A>G"]` | The allele's genomic HGVS on GRCh37 (chr7). |

## Why it works

dbSNP rsIDs name a position and can cover more than one change. BioMCP keeps every source candidate and does not pick one. The candidate whose ClinVar ID is `clinvar:13961` is the A>T change that encodes BRAF V600E; its `next` command reads it with `--build GRCh37`.

## Limits

The HGVS here is on the build MyVariant.info used, GRCh37. `biomcp variant normalize` converts it. An rsID absent from MyVariant.info returns no candidates, which is not proof it does not exist.
