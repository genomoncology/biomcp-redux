05-variant-pathogenicity: Inspect native variant assertions

07-gene-function-localization: Inspect protein features after gene resolution
08-mechanism-pathway: Read an identified pathway record
09-trial-recruitment: Screen registry records in explicit stages
10-pharmacogene-cumulative: Read separate pharmacogenomics tables
11-disease-locus-mapping: Find genes in a stated cytoband
12-cellular-process-regulation: Inspect pathway membership and events
13-mutation-catalog: Inspect candidates at an explicit genomic position
14-syndrome-disambiguation: Resolve an ambiguous gene name before disease review
15-negative-evidence: Distinguish empty from unavailable source sections
16-normalize-to-codes: Keep normalization services independent
17-exact-variant-literature: Search literature with an explicit variant term
