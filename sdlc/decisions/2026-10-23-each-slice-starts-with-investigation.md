# Each slice starts with investigation

Decided 2026-10-23 by Ian.

- BioMCP 0.9 is not the spec. Each slice looks critically at every existing command, section and option for its entity.
- Each slice starts by finding real examples in published papers and real questions, and by seeing how the sources answer them. Those findings drive the biodata types, the schemas, the outside-in cases and the command behavior.
- Each slice answers five to ten questions about what would delight the agent user, from the template in `planning/slices.md`.
- Clinical judgments in an investigation go to a clinical reviewer.
