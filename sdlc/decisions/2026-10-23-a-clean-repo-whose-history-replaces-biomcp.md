# A clean repo whose history replaces BioMCP's

Decided 2026-10-23 by Ian.

- BioMCP 1.0 is built in this new, clean repo, not on top of the 0.9 code or its old 1.0 branch.
- 1.0 ports knowledge, not code: source quirks, the facts the 0.9 tests protect, recorded replies worth keeping, help text and the release pipeline.
- When 1.0 reaches parity and Ian approves the release, this repo's history replaces the BioMCP repository's history. The GitHub repository keeps its stars and release history.
- Why: the 0.9 code's problems are structural and spread across every layer. A clean layout costs less than untangling it.
