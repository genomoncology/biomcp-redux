# 0018 — Decode checked XML replies through the shared transport

Status: OPEN.

Milestone: 1

## Outcome

Leg::xml returns checked typed replies from declared GET or form endpoints through all transport modes, and MixedText preserves inline element text in document order.

Depends on: 0017

- Starts from: architecture 4.2 and the MixedText contract in 5.4; request.rs Leg::send/attempts/decode; cache_request.rs checked_cached/offline; record.rs text bodies; declaration.rs endpoints; existing transport stub and public contracts. Read the POST branch after it lands for exact prepared-request boundaries.
- Changes: `Cargo.toml`, `Cargo.lock`, `crates/biomcp-fetch/Cargo.toml`, `crates/biomcp-fetch/src/lib.rs`, `crates/biomcp-fetch/src/xml.rs`, `crates/biomcp-fetch/src/xml_tests.rs`, `crates/biomcp-fetch/src/request.rs`, `crates/biomcp-fetch/src/cache_request.rs`, `crates/biomcp-fetch/src/cache.rs`, `crates/biomcp-fetch/tests/xml.rs`, `crates/biomcp/tests/ratchets/source.rs`, `sdlc/planning/architecture.md`.
- PM decision: 2026-10-24, m4291. Accept application/xml, text/xml and application/*+xml with parameter/case normalization. UTF-8 only, optional BOM, absent/UTF-8 charset/declaration; conflicting encodings fail, new encoding waits for actual source. DOCTYPE is inert and never fetched; only built-in/numeric references, custom references fail. MixedText preserves order/whitespace, ignores attributes and defaults empty. Keep sub/sup recognisable in its named inline table through preserved text. Request keys/recordings unchanged. Canonical XML codec is application/xml; preserve existing application/json. Unknown/mismatched cached codec evicts as a miss; callers with same request but another decoder may safely replace entries.
- Scope: Add Leg::xml<T: XmlReply> for existing GET/form endpoint and Arg shape. Select XML Accept/media/decoder within the same prepared-request, quota, deadline, attempts, body-limit, cache and mode path. Use quick-xml 0.42 with only serialize feature. Parser/check failures are input-free bad_reply. Persist/read canonical codec via existing reply.content_type without schema or JSON key changes. All modes use selected decoder and accepted invalid-entry rules. PM decision m4298: XmlReply::decode_xml is the explicit raw XML boundary, with a bounded serde default for ordinary replies. MixedText::from_xml reads mixed element fragments with quick-xml Reader and preserves exact whitespace. MixedText has Default and a read-only accessor; its ordinary string Deserialize does not promise arbitrary $value XML decoding. No vendored dependency. Fold ordered text and nested arbitrary element content without retained tree/tag whitelist; ignore attributes/comments, preserve whitespace without separators, decode references/CDATA, empty content is empty string. Update the architecture PubMed sketch to select mixed elements explicitly and use serde for other fields. Bound the parser and iterative MixedText reader with the shared nesting limit; keep parser checks, reject incomplete/trailing document content and retain deadline checks around decode/check.
- Checked dependency boundary: quick-xml 0.42 Reader preserves the raw text/reference/CDATA event order; the kept table checks `<raw> A <sub>2<sup>+</sup></sub> <i>x</i> </raw>` as ` A 2+ x `. Its serde path decodes `<reply><answer>true</answer></reply>` as an ordinary typed boolean reply, but discards whitespace-only events in arbitrary `$value` mixed fields. The explicit XmlReply override avoids that limitation. No source-specific XML vocabulary or live provider behavior is assumed by this ticket.
- Keeps: Existing JSON/GET/POST keys/captures remain usable. Reply::check remains the validity boundary. Preserve quota/retry, checked absence, stale fallback, record bypass, replay isolation and offline rules. No adapter, biological mapping, provider calls, CLI grammar, custom DTD resolver, DOM or parser framework.
- Proof: Shared-stub public API contracts prove checked GET/form XML, media/encoding/malformed refusal, check rejection, body/nesting bounds and existing deadline boundary. Cover cache reuse, codec mismatch and invalid XML eviction, stale fallback, record text then replay without server, offline reads. One permitted MixedText table lives in cfg(test)-only xml_tests.rs, excluded by the source coverage filter, and calls the explicit Reader helper for nested/interleaved sup/sub/i/b and unknown tag, spaces, numeric/predefined references, CDATA, attributes and empty content; retain variant text. Include inert external DOCTYPE and rejected custom entity. Reuse unchanged JSON/POST evidence; make landing-gate through pm job after main.
