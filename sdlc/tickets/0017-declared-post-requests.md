# 0017 — Send declared form and JSON POST requests through the shared transport

Status: OPEN.

Milestone: 1

## Outcome

Declared form and JSON POST endpoints use the same checked request, quota, deadline, retry, cache, record and replay path as GET, with method/body identities that cannot reuse another request's reply.

Depends on: 0014

- Starts from: architecture 4.2 and 4.4–4.7; declaration.rs Endpoint/SourceSpec/Arg; request.rs Leg::{json,json_opt}, send, attempts, call, exchange and decode; retry.rs canonical/identity; cache_request.rs; record.rs recording identity validation in the accepted 0014 branch.
- Changes: `crates/biomcp-fetch/src/prepared.rs`, `crates/biomcp-fetch/src/declaration.rs`, `crates/biomcp-fetch/src/lib.rs`, `crates/biomcp-fetch/src/request.rs`, `crates/biomcp-fetch/src/retry.rs`, `crates/biomcp-fetch/src/cache_request.rs`, `crates/biomcp-fetch/src/record.rs`, `crates/biomcp-fetch/src/error.rs`, `crates/biomcp-fetch/tests/post.rs`, `crates/biomcp-fetch/tests/support/**`.
- PM decision: 2026-10-24, m4288. Add const SourceSpec::post_form/post_json and Endpoint::idempotent(); POST defaults non-idempotent, GET stays idempotent. Add input-free RequestError::Input(InputError) for method mismatch, serialization and body limit; local failures never trigger stale fallback. Existing max_body independently bounds encoded request and response bytes. Preserve GET keys/files exactly. POST metadata stores method POST, request content type and SHA-256 of the credential-free encoded body, never the body; validate before cursor movement. POST cache identity uses that same body hash with unambiguous encoding/URL framing.
- Scope: Add declared form and JSON POST endpoints with private fields. json/json_opt accept GET or form POST; post_json<B: Serialize,T: Reply> accepts only JSON POST. Check required key, source ownership, clock domain and method compatibility before preparing a body or accessing request storage. Prepare encoded bytes once through a bounded writer, check deadline again, and reuse exact bytes for hashing and every attempt. Form parameters retain caller order and duplicates, correct percent encoding and sorted Arg::Ids. Remove configured query-credential parameters from caller parameters as GET does; insert configured query/header credentials only at wire construction. Keep credentials out of prepared bodies, identities and metadata. Share quota, retry, decoder/check, cache and modes. POST retries require explicit idempotence; otherwise HTTP makes at most one admitted attempt with no retry wait. Retain status/Retry-After reporting. Local preparation errors never become provider failures or stale successes. No JSON semantic canonicalization, middleware or optional POST API.
- Keeps: No HTTP-client duplication, new runtime, external provider calls or adapter consumer before the shared transport is complete. Record bypasses cache reads/fallback; replay never falls through to HTTP or ordinary cache. Keep checked 404 absence and stale-positive rules. No generic request middleware or premature CLI flags.
- Proof: Extend the shared local stub to read complete bounded bodies and expose method, headers and bytes. Public API tests inspect escaping, spaces/plus, Unicode, duplicates, sorted IDs, JSON bytes and content types. A stateful serializer proves one serialization across retries. Oversized/failing serialization returns typed local errors without HTTP, cache-entry access or recording read/append; Fetch opening is outside this assertion. Warm-cache and replay cases distinguish method, encoding and body while identical requests match. Existing GET recording fixtures and cache identities remain usable. Inspect configured credential transmission and absence from identities, captures and diagnostics. Exercise idempotent retries, non-idempotent single attempts, checked rejection, record bypass, replay without server, replay miss despite warm ordinary cache and later offline reads from case-owned cache. Existing GET contracts and make landing-gate pass through pm job after current main.
- Defers: XML/MixedText and bounded scoped batch fan-out are subsequent whole transport steps before adapters. Binary recording sidecars arrive with the first article supplement source. Query grammar and normal output envelopes arrive with the first gene command.
