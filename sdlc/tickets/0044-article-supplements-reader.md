# 0044 — Add the supplements section and the article supplement reader

Status: OPEN.

Milestone: 1

## Outcome

`get article <input> supplements` lists each supplementary file the PMC OA bucket holds with its name, kind, label, caption and the article's license, and `article supplement <ID> <FILE>` returns an xlsx, csv, tsv or txt file's sheets with row counts, a page of rows with `--rows A-B`, the rows matching the literal `--find TEXT` with sheet, row number, header row and the file's SHA-256, where the header row is the sheet's first row, or the rows matching any form of a protein change given by `--variant CHANGE`, which `article text` also takes, through the CLI and MCP.

- PM decision: 2026-10-24. biomcp-fetch gains a bytes reply: an endpoint may declare a body limit above `max_body`, here 50 MB, and `Leg::bytes` returns the checked body; record mode writes it as per-exchange `.bin` sidecars beside the exchange file and replay serves it. biomcp-adapters may import `calamine` and `csv`, recorded in architecture 2.1, 2.2 and the ratchet's allowed list; the stage runs `cargo deny` and brings each license outside the allowlist through a pinned exception. The `sheet/` module reads xlsx with calamine, csv and tsv with csv, and txt as one column of lines; pdf, docx and every other kind return `unsupported` with the file's URL and no download. `Section<Supplements>` holds `license` and every file named in JATS `supplementary-material` that the record lists, each with `name`, `kind` (`FileKind`), `label` and `caption`. `article supplement` takes a PMID or PMCID, the file name exactly as listed, and `--rows A-B` (at most 200 rows, with `--sheet NAME` required when the file has more than one sheet, because rows are numbered per sheet; --sheet is approved in m4339) or `--find TEXT` (25 hits per call with a page step), never both; without either it returns the sheets with row counts and a step for the first rows. Every reply names the license and the SHA-256, computed in biomcp-query. `--find` matches literally without case and never inspects the needle's shape, as `decisions/2026-10-24-no-text-heuristics.md` rules. `--variant CHANGE` is the explicit option: biodata's typed `ProteinChange` parse reads the change with the standard one-letter and three-letter amino-acid codes, plus Ter and `*`, the reply prints the forms it searched (`P245S`, `Pro245Ser`, `p.P245S`, `p.Pro245Ser`), and a row matches when it holds any form, literally and without case. A change that does not parse is a usage error before any download. `article text` takes the same `--variant` over 0043's parts. `--find`, `--variant` and `--rows` are mutually exclusive. The card's section step and `more` name `supplements` only when the card has a PMCID, and the section's `next` holds `article supplement <PMCID> <first readable file>`.
