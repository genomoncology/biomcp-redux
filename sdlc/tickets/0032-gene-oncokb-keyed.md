# 0032 — Add OncoKB as a keyed gene source

Status: OPEN.

Milestone: 1

## Outcome

With the user's OncoKB key, `get gene` adds a short OncoKB block to each resolved card and `get gene <input> oncokb` returns OncoKB's gene summary, background and transcripts. Without a key, BioMCP sends no OncoKB request, names OncoKB once as skipped with reason `no_key`, and offers one `key` step whose `biomcp help key oncokb` names the config key and environment variable. Proven by gene.md case 19 in the repo and synthetic keyed cases.
