# 0108 — Label every source outcome with its terms

Status: OPEN.

Milestone: 2

Depends on: 0106

## Outcome

Each source outcome in every response envelope carries that source's `use`, terms name and publisher page, derived from the one source registry that `biomcp health` already reads, as `decisions/2026-10-24-sources-are-open-by-default.md` requires. Today only `health` shows them.

- Starts from: 0057's `SourceSpec` terms and `Use`; the envelope's source outcomes; the response types after 0106 moves them.
- Keeps: 0092's component labels, whose blocking also derives from the same registry; no second terms table.
- Proof: a gene, an article and a trial case each assert the terms fields on every source outcome; a ratchet refuses an outcome built without registry terms; output ceilings rise only by the measured terms bytes. Then make landing-gate runs through pm job after current main.
