## Outcome

The biodata public API supplies the identifier pattern, partial calendar dates and typed coordinate bounds that the first entity slice can reuse, with checked JSON construction and schemas.

Depends on: 0005

- Starts from: `sdlc/plan.md` stage 3; architecture sections 3.1, 3.2 and 3.9; `crates/biodata/src/lib.rs`, `source.rs`, `text.rs`, `tests/core.rs`, `tests/schemas.rs` and `tests/schemas/{values,compatibility,compatibility_cases}.rs`. The current canonical-value macro lives in source.rs; macros.rs and error.rs do not yet exist.
- Changes: `ROADMAP.md`, `crates/biodata/src/lib.rs`, `crates/biodata/src/macros.rs`, `crates/biodata/src/error.rs`, `crates/biodata/src/date.rs`, `crates/biodata/src/coord.rs`, `crates/biodata/src/id/mod.rs`, `crates/biodata/schemas/hgnc-id.json`, `crates/biodata/schemas/partial-date.json`, `crates/biodata/schemas/position1.json`, `crates/biodata/schemas/span0.json`, `crates/biodata/tests/value_conventions.rs`, `crates/biodata/tests/schemas.rs`, `crates/biodata/tests/schemas/values.rs`, `crates/biodata/tests/schemas/compatibility.rs`, `crates/biodata/tests/schemas/compatibility_cases.rs`, `crates/biodata/README.md`.
- Scope: Establish the private-field identifier pattern with HgncId as the first real identifier: checked positive numeric construction, canonical HGNC text with ASCII decimal digits and no leading zeros, signs, whitespace or alternate-case prefix, FromStr and Display, Hash with Eq, JSON through the same parser and a string schema with its pattern. Share textual serde/schema boilerplate without copying canonical facts. Add PartialDate at year/month/day precision with real calendar checks, and Position1 plus Span0 with the counting and bounds rules from architecture 3.2. HgncId uses private NonZeroU32, new(u32) and get(); JSON accepts strings only. Error enums use stable codes needed by actual validation and retain no rejected text, without an unused catalog. Keep schemas optional and checked in through the existing registry.
- PM decision: 2026-10-24. PartialDate supports years 1–9999 as exact YYYY, YYYY-MM or YYYY-MM-DD strings, Gregorian checks and preserved precision, with no day without month and no whitespace/trailing data. Nothing fills missing components. Adapters handle source seasons/ranges and leave a problem for unsupported detail.
- PM decision: 2026-10-24. Position1 is a positive u32 JSON integer. Span0 has private u32 bounds and half-open {start,end} JSON, start<=end with empty spans allowed, checked deserialization and unknown fields rejected. Biological meaning, assemblies and conversion remain outside this ticket.
- Compatibility: Extend the existing bounded checker only for new patterns, integer types and numeric bounds these schemas emit. Reject changed patterns within a major and tightened numeric bounds; preserve rejection of unsupported forms. Schemas describe canonical serialized values; calendar validity, numeric text overflow and relational span bounds remain runtime constructor/serde checks when JSON Schema cannot express them.
- Keeps: No gene entity, provider grammar, gene symbol parser or other entity identifiers before their slice needs them. No default genome assembly, coordinate conversion or clinical interpretation. Values are immutable and constructors/deserialization enforce the same invariant. biodata stays free of I/O and dependency expansion. No generic binding-hostile public types.
- Proof: Public API boundary tables first fail without the types, then prove construction/serde parity, canonical text round trips, zero/overflow/malformed identifier rejection, partial-date precision, leap and invalid calendar dates, and coordinate boundaries. Errors omit distinctive bad input. Validate representative serialized values against schemas. Reject wrong JSON types, malformed canonical strings, numeric bounds, missing coordinate fields and unknown fields through the appropriate schema/runtime boundary. Run drift and bounded compatibility tables including changed patterns and tightened numeric bounds. Run make landing-gate through pm job after merging current main before review.
- Defers: GeneSymbol, other identifiers, Build, Contig and GenomicInterval arrive with the gene slice against its source formats. Query/envelope/section types and their schemas follow separately. ROADMAP ticks belong only to the landing candidate when its entire item is satisfied.
