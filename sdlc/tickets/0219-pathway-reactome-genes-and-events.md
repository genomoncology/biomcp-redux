## Outcome

`get pathway R-HSA-5673001 genes` returns the first five source membership references from Reactome's physical participants, following the publisher's reference entities and identifier namespaces, each with its namespaced source reference, its source label, its reference class and an optional HGNC ID resolved through the existing checked HGNC map, with the actual relation counts. `get pathway R-HSA-5673001 events` returns the first five native contained events with their native identifiers and classes and the relation total. `pathway genes R-HSA-5673001` and `pathway events R-HSA-5673001` page the retained relation with `--limit`, `--offset` and `--pool`, following the existing record-parts pattern. `get pathway R-HSA-5673001 all` returns the card, the summary and each section's bounded first page.

- Why: questions 24 to 26 ask which exact gene references the source lists as RAF/MAPK participants, and the design keeps Reactome genes and events behind explicit disclosure.
- Starts from: pathway.md's public fields and identity joins, delight questions 3, 4 and 6, command table, measured disclosure costs and case matrix; the 2026-10-26 pathway rulings; the j14201 participant and event captures for `R-HSA-5673001`; 0216's dispatch, card and pool code; 0209's types.
- Rules: no symbol is extracted from a display name by regular expression or otherwise, and a physical participant is never counted as one gene. A UniProt reference resolves only through the existing checked HGNC map; a reference without an exact join stays a source reference with a problem and no gene action. Isoforms such as `P01116-1` and `P01116-2` stay separate members, and several proteins that map to one gene keep their source membership. A `ReferenceTherapeutic` reference keeps its exact namespace and source URL and never yields a drug step. Totals say whether they count reference occurrences, distinct references or physical entities. An event keeps the object or integer reference distinction; an integer reference is hydrated only by a checked request that a capture in this ticket proves, and otherwise stays an explicit unresolved record. An event never inherits the pathway's stable ID. Only an event whose captured class is `Pathway` or `TopLevelPathway` gets a `get pathway` step; reactions and other events keep their source references and URLs. `all` never runs enrichment. No whole-pathway drug, article or trial fanout. Next steps follow architecture 6.10: a genes page gives one pivot per distinct resolved gene in source order, then the page step; an events page gives the page step before at most three other steps.
