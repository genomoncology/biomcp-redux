- PM decision: 2026-10-24. Resolution: an HGNC ID matches the complete set, then the withdrawn file. An Entrez or Ensembl ID matches the Xref keys by base accession. Text that matches an approved symbol resolves. Otherwise the previous-symbol and alias matches join by distinct HGNC ID, and a record matched both ways keeps the previous-symbol kind. One record resolves and several are ambiguous. Then a withdrawn symbol answers withdrawn, and nothing answers not found. Ambiguous candidates rank by match kind, then protein_coding first, then HGNC number. Match text is the source spelling that matched. `merged_into` lists every stated HGNC ID without following chains. NcbiAlias is never produced.
