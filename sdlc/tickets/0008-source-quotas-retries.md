# 0008 — Enforce shared source quotas and deadline-bound retries

Status: OPEN.

Milestone: 1

## Outcome

Every request acquires its declared source quota, shares provider limits across source legs, and retries only the approved failures within its leg deadline.

Depends on: 0004
Depends on: 0007

- Starts from: `sdlc/plan.md` stage 4; architecture sections 4.2, 4.5, 4.6 and 4.7; the existing biomcp-fetch request path and public transport tests. Follow the approved staged API by adding quota fields only when enforced.
- Changes: `crates/biomcp-fetch/tests/support/mod.rs`, `crates/biomcp/tests/ratchets/source.rs`, `Cargo.toml`, `Cargo.lock`, `deny.toml`, `crates/biomcp-fetch/src/lib.rs`, `crates/biomcp-fetch/src/declaration.rs`, `crates/biomcp-fetch/src/error.rs`, `crates/biomcp-fetch/src/request.rs`, `crates/biomcp-fetch/src/quota.rs`, `crates/biomcp-fetch/src/retry.rs`, `crates/biomcp-fetch/tests/transport.rs`, `crates/biomcp-fetch/tests/quotas.rs`, `crates/biomcp-fetch/tests/retries.rs`, `crates/biomcp-fetch/Cargo.toml`, `crates/biomcp/tests/ratchets/dependencies.rs`.
- Scope: Add SourceKey, Rate and Quota with validated construction and SourceSpec's declared quota. One Fetch owns limiter state keyed only by SourceKey. Sources sharing a quota share FIFO rate and in-flight limits. Required-key refusal remains before any permit acquisition or request. Apply the declared keyed rate only when a credential exists. Each attempt acquires rate and in-flight limits. Hold its in-flight permit through body consumption or failure, release before backoff and reacquire on retry. Expired/canceled waiters remove their queue entry and wake successors. Extend the existing GET path with retries and Retry-After seconds or HTTP-date parsing as section 4.6 specifies. Classify retryable connect timeout/reset before conversion to SourceError; never retry body truncation, decoding, failed Reply::check or exhausted deadlines. Keep retry attempts and backoff values defined once in code following section 4.6. Jitter uses an internal stable identity from method and canonical URL before credential insertion, excluding query/header credentials; reuse this identity for the later cache without exposing public cache methods. A valid Retry-After beyond the remaining budget returns RateLimited immediately with an optional typed retry duration on SourceError. Ordinary quota/backoff expiry returns DeadlineExceeded. Malformed Retry-After falls back to backoff; past dates mean zero wait.
- Reviewed implementation detail: Use approved sha2 for stable request identity. If the current stack exposes no HTTP-date parser, prefer a small maintained httpdate dependency to owning calendar parsing; confirm current version/features and license metadata, document the code saved and upkeep in its commit, and add it to the fetch dependency policy. This changes no product outcome.
- Keeps: No limit derived from URL, host or endpoint. No per-adapter scheduler, worker pool, async runtime or parallel retry implementation. No provider calls or adapters yet. No cache, replay, bundle or XML placeholders. Keep source deadline caps, body/reply checks and credential secrecy. Add only dependencies whose saved parsing/code cost is recorded and update exact license metadata in this ticket if needed.
- Proof: Public API tables and local-server cases prove shared-key spacing and in-flight caps across two source specs, independent keys, keyed and unkeyed rates, FIFO progress after cancellation, and permit release after failures. Hold one permit, expire a queued waiter, then release the holder and observe a later waiter succeed; do not infer arrival order from thread launch order. Exercise the GET retry status table, exhaustion, both Retry-After forms and wait beyond deadline. Use events and observed request starts rather than fixed startup sleeps or tight wall-clock success ceilings. Keep slow/exhaustive concurrency outside routine checks. Run make landing-gate through pm job after merging current main into the completed branch before review.
- Defers: POST and its idempotency refusal case arrive when POST behavior is implemented. The next transport step supplies SQLite reply cache, record/replay/offline and virtual quota time. Adapter quota statics arrive with adapters; test fixtures exercise the public declarations under the existing library-test exception. No transport roadmap tick until the whole stage is complete.
