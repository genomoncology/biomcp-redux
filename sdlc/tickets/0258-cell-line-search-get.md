# 0258 — Search Cellosaurus cell lines and get the cell line card

Status: OPEN.

Milestone: 4

Depends on: 0257

## Outcome

`search cell-line MOLM13` sends one literal Cellosaurus search with native `start` and `rows` and returns five headers in source order, each with the primary accession, recommended name, category and at most three species and disease references, and the next offset only when the window fills, with no total claim. `get cell-line CVCL_2119` returns the `CellLineCard` from one Cellosaurus card request: header facts, entry created, updated and version values, age and sex when supplied, at most three complete qualified warnings, the publisher URL, the `more` list of sections and at most five section or pivot steps. `get cell-line DepMap:ACH-000362` searches the exact qualified cross-reference, then verifies that database and accession on the exact card before returning it. Several candidates return as candidates with one get each. Cellosaurus registers as an `open` source with its CC BY 4.0 attribution and its record URL template.

- Why: Questions C01, C02, C06, C08 to C11 and C13 ask which exact line a published spelling or source ID denotes, and the design answers them with native search and an exact identity card.
- Starts from: cell-line.md's command tree, source paging, delight questions, case map and measured budget, with the cell line rulings; 0256's witnesses; 0257's types; the source registry and record URL templates from 0250; the shared transport, cache and next steps in `architecture.md` 4 and 6.10.
- Rules: no name normalization, punctuation removal, second hyphenless search or human-first reranking, per the cell line rulings. One unchanged query per search. No search result, sole candidate or name match selects identity without the exact card check. A returned accession that differs from the request is dropped unless it is the requested secondary accession that 0256 proved. A well-formed accession with no record is absent, and a failed request is failed. Cellosaurus release metadata is a separate cacheable provenance read, and its failure labels retrieval time and adds a problem. Next steps follow `architecture.md` 6.10: a search page gives one get per shown accession, then the page step; the card gives at most five steps in the order names, variants, xrefs, ChEMBL, then identity overflow. Every emitted accession round-trips through its command. A warning is never turned into a present assertion about every stock.
- Proof: outside-in cases first, watched to fail. Cases reuse the j14318, j14323, j14325 and 0256 captures where the request matches exactly, and one bounded keyless pm job captures once, with zero retries, any exact request a case needs that those archives lack. C01 asserts `search cell-line MOLM13` returns CVCL_2119 alone; C02 asserts `MV4;11` returns CVCL_0064 with the query sent unchanged; the NB4 cases assert the first window CVCL_8811 to CVCL_U081, the second window from offset five with no overlap, a next offset on each full window and no total; KG1 asserts three candidates with mouse species on the first and third; the unknown literal asserts a successful empty distinct from failure; C08 and C09 assert the K-562 and NB4 cards; C11 asserts HL-60 and HL-60(TB) as separate cards; the U-937 card asserts its complete stock-qualified warning; C13 asserts the reverse get to CVCL_2119; 0256's ChEMBL-ID and ambiguous reverse searches assert their outcome or the stated deferral; the absent accession asserts absent distinct from failed. A synthetic wrong returned accession and a reverse get whose card lacks the requested cross-reference assert the drop or refusal and no cache admission. Recorded 429, 500, timeout, broken JSON and HTTP 200 HTML replies assert a failed outcome with source and terms, never an empty page. Paging usage cases cover a zero and an over-25 limit and a negative offset. The job measures each command in CLI and MCP output, starting from the design ceilings of 5,267 bytes for five headers and 1,510 bytes for the card payload, and each case gets a ceiling at measured size plus 15 percent, recorded in cell-line.md. No licensed content enters the repo. Then make landing-gate runs through pm job.
