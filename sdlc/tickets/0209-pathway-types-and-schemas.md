# 0209 — Add the pathway types and generated schemas

Status: OPEN.

Milestone: 4

Depends on: 0206

## Outcome

`biodata` holds the neutral, no-I/O pathway records that `planning/slices/pathway.md` names: a tagged `PathwayId` that holds either a checked human Reactome stable ID or a checked WikiPathways ID, `Pathway` with identity, native name, source-stated human species and source description, `PathwayMember` with its namespaced source reference and optional resolved HGNC ID, `PathwayEventRef` with its native object or integer database reference, and namespaced source identifiers. The existing checked `ReactomeId` and `PathwayRef` stay the one source of truth, reached through one reviewed move or wrapper, and the gene schemas stay byte-identical. `biomcp-types` holds the consumer side: the `search pathway` request with positional text, `--gene`, `--top-level`, `--source reactome|wikipathways` defaulting to Reactome, `--limit` with default 5 and checked maximum 50, `--offset`, `--pool` and `--fresh`; the `get pathway` request with the sections `summary`, `genes`, `events` and `all`; the `pathway genes ID` and `pathway events ID` continuation requests with `--limit`, `--offset` and `--pool`; the pathway header, the card, the header page and the genes and events section pages; and the `sync wikipathways` receipt fields. The generated, checked-in schemas cover the pathway page, the pathway card and the genes and events pages.

- Why: the slice method lands types and schema before adapters, and the accepted design with the 2026-10-26 pathway rulings fixes the records, the command tree and the page shapes.
- Starts from: pathway.md's public fields and identity joins, proposed types and schema, command table and outside-in case matrix; the 2026-10-26 pathway rulings, which win over the design text; 0206's witnesses and the 0191 evidence archive's field and optionality inventories; `ReactomeId`, `PathwayRef` and `Capped` in `crates/biomcp-types/src/response/gene/pathways.rs`; `rust-standards.md`.
- Rules: no second Reactome ID type and no second pathway reference type. A changed `PathwayRef` wire shape is versioned, and the gene pathways section keeps its current shape. A Reactome stable ID's version is a separate source field, and a WikiPathways revision stays separate from its WP identity. A non-human Reactome ID or a malformed WP ID fails to parse before I/O. A participant display name is never a gene symbol, a member keeps its namespace and value together, and several proteins that map to one gene stay separate members. An event never inherits the pathway's stable ID, and an integer event reference stays an explicit unresolved reference until it is hydrated by a checked request. No generic unchecked string replaces a checked identifier. Text, `--gene` and `--top-level` are mutually exclusive, and `--top-level` and `--gene` are Reactome only. `events` is Reactome only, and `genes` on a WikiPathways ID fails before I/O until the GPML genes ticket lands. There is no `--type`, no `-q` or `--query`, no `enrichment` section and no pathway drug, article or trial request type. Optional absent scalar fields are omitted, and a page says whether its total is the source's or observed.
- Proof: cases first. Type review checks each field's absence, multiplicity and collection scope against the 0191 captures and 0206's witnesses. Round-trip tests cover each ID form and each closed set, including refusal of `R-MMU-` IDs, KEGG `hsa` IDs and malformed WP IDs, each selector conflict and each unsupported source and section pairing before I/O. The generated schemas are checked in with snapshot and compatibility checks, and existing schemas stay unchanged, with the gene schemas byte-identical. This ticket adds no filter or exact-ID get and makes no provider call; each filter and exact-ID get that later pathway tickets add has a known-positive capture through one bounded keyless pm job. Then make landing-gate runs through pm job.
- Defers: executable help, Markdown parity and the shared request, step and envelope schema versions move to 0216, which registers pathway in the shared request. The WikiPathways member fields that GPML carries move to 0224.
