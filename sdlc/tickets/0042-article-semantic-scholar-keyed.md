# 0042 — Add Semantic Scholar as a search source with an optional key

Status: OPEN.

Milestone: 1

## Outcome

`search article … --source …,semantic-scholar` folds Semantic Scholar's relevance order into the pool with or without the user's key, resolves its DOI-only rows to PMIDs where a PubMed record carries the same DOI, paces keyless calls at a conservative shared-pool quota, uses the user's optional key for the higher limit without ever printing it, and reports a 429 that outlasts the retries as a failed leg with reason `rate_limited` and a `key` step, through the CLI and MCP.

- PM decision: 2026-10-24, revised the same day after Ian's ruling. `Source::SemanticScholar` spells `semantic-scholar` everywhere. The adapter declares `KeyUse::Optional` with `SecretName::SemanticScholarApiKey` in header `x-api-key`, config `keys.semantic_scholar_api_key` and environment `SEMANTIC_SCHOLAR_API_KEY`, and `help key semantic-scholar` says the key is free and raises the limit. The `semantic-scholar` quota is 1 request every 2 seconds with one in flight without a key, and 1 per second with the key; 0050, 0051 and 0052 share it. A 429 retries as architecture 4.6 says; when the retries run out, the source outcome is failed with reason `rate_limited` and the response adds one `key` step. The key is outgoing only, as for NCBI: never in a request key, recording, trace, error or envelope. It asks one page of 100 with `fields=externalIds,title,venue,year,publicationDate,authors`. Rows with a PubMed ID key on it. Rows with only a DOI are resolved by one ESearch per 100 DOIs, `A[doi] OR B[doi]`, and each returned PMID is kept only when its ESummary DOI equals the row's DOI without ASCII case; other rows keep the DOI and a header from Semantic Scholar with `types_unknown`. Semantic Scholar applies the words, `--gene` as typed, `--variant`, `--disease`, `--drug` and `--since`/`--until` as `year=A-B`; `--author`, `--journal`, `--type` and `--sort date` are `usage.unsupported_filter` until a recorded reply shows each mapping, which narrows article.md's filter table. `--help` gains the `semantic-scholar` line from article.md.
