## Outcome

`protein features P00533 --position 858` returns the source features whose exact checked bounds contain residue 858 of the displayed sequence, five rows per page, each with its exact native type, coordinates and evidence. `--type Domain` selects one UniProt feature type by its exact native label before paging, and `--position` and `--type` together select their conjunction. `protein isoforms P00533` returns the native alternative-product rows with each stated isoform ID, name, synonyms, Displayed, Described or External status and source sequence IDs. `protein structures P00533` returns UniProt's PDB cross-reference rows with method, resolution and chains or ranges when present, and a link to the publisher record. `protein sequence P38398-2` returns one exact native sequence with the returned accession and audit metadata. `get protein P00533 features`, `isoforms`, `structures`, `sequence` and `function` return the same first page under `--section-limit`, and `function` returns the source function text with its evidence. The card from 0245 gains its steps for these sections.

- Why: residue questions P01, P02, P05, P10, P11, P14, P17, P25 and P26 ask which source feature contains a displayed residue, and P04, P13, P15, P19, P20 and P27 ask which isoforms the source describes and which sequence qualifies a number.
- Starts from: protein.md's command tree, case table and measured budget section, with the 2026-10-26 protein rulings; the j14202 entry captures and the j14211 and j14221 FASTA captures; 0245's UniProt adapter and dispatch registration; 0233's types.
- Rules: the sections read the retained UniProt entry reply, with no new request for a section the entry already holds. A base accession's sequence comes from the retained entry, and an isoform accession's sequence comes from UniProt's exact FASTA, whose returned identity must match the requested isoform or the reply is dropped with a problem. A sequence is never truncated. Features belong to the isoform their record states, and a position query on another isoform is refused, because displayed coordinates never transfer to an alternative isoform. A feature without exact bounds joins a position overlap only when its uncertainty proves containment. Source feature labels stay distinct, so a RING-type Zinc finger never reads as a Domain feature. A position overlap names the source feature and makes no mutation effect, efficacy, resistance or oncogenicity claim, and a historical residue label such as V599 or G382D is never translated. An External alternative keeps its own accession, and no `-1` is synthesized where the record does not list it. An isoform row offers a get or sequence step only where a capture proved that identity can be retrieved. A structure reference never claims that the structure covers a residue, and a missing provider credit never panics. No alignment, prediction or structure tool runs.
- Proof: outside-in cases first, watched to fail. Cases reuse the j14202, j14211 and j14221 captures where the request matches exactly, and one bounded keyless pm job captures once, with zero retries, any exact request a case needs that those archives lack. P01 and P26 assert P00533 Protein kinase 712 to 979 for residues 858 and 797, and P02 asserts residue 790 in the same range with the active site at 837 as a different annotation; P05 asserts P15056 Protein kinase 457 to 717 for residue 600; P10 asserts BRCT1 1642 to 1736 and BRCT2 1756 to 1855 as separate rows under `--type Domain` with nothing for the gap between them; P11 asserts the Zinc finger RING-type 24 to 65 under its own type; P14 asserts P04637 DNA binding 102 to 292 under `--type 'DNA binding'`; P17 asserts P13569 ABC transporter 1 at 423 to 646 for residue 508; P25 asserts P31749 PH 5 to 108 for residue 17, separate from the kinase at 150 to 408. Position cases cover each exact endpoint, a residue past the sequence length, position zero, an alternative isoform and the type and position conjunction. P04 asserts P00533-1 to P00533-4 with their status; P15 asserts P04637-1 to P04637-9 across pages of five; P27 asserts Q9UIF7-2 to Q9UIF7-6 as alternatives; P20 asserts External products keep their own accession. P13 asserts the exact P38398-2 sequence of 63 residues distinct from displayed P38398, and the Q9UIF7-2 case asserts 536 residues; P19 asserts Q9UIF7's displayed sequence with S368 and G393 and no alias conversion; the BRCA1 case asserts the complete 1863-residue sequence. Sequence cases cover a mismatched returned ID and invalid residues. Structure cases assert source PDB IDs and properties, pages and a section failure that never reads as empty. Recorded 429, 500, timeout and broken-body cases assert a failed outcome with source and terms. The job measures each command and section in CLI and MCP output, starting from the design ceilings of 10,210 bytes for features, 2,601 for isoforms, 2,438 for structures, 3,729 for sequence and 12,179 for function, and each case gets a ceiling at measured size plus 15 percent, recorded in protein.md. No licensed content enters the repo, and replies whose terms bar storage replay from outside the repo. Then make landing-gate runs through pm job.
