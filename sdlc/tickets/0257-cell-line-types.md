## Outcome

`biodata` holds a checked Cellosaurus accession, a source-qualified cross-reference, Cellosaurus entry dates and version, the cell identity with species and disease references, the complete qualified warning, the native name entry and the native variation record with its gene members, references and provenance rows, all with no I/O. `biomcp-types` holds the `search cell-line` request with a positional query or `--query`, `--limit` from 1 to 25 with a default of five and a nonnegative `--offset`; the `get cell-line` request with one accession or one database-qualified source ID, the sections `names`, `identity`, `xrefs`, `variants`, `chembl` and `all`, `--section-limit` from 1 to 25 and `--section-offset`; the `cell-line assay-count CHEMBL_CELL_ID` request; and the `CellLineHeader`, `CellLineCard`, names, identity, xrefs and variants pages, the ChEMBL metadata reply and the assay-count reply. The generated, checked-in schemas are `biomcp.cell_line_page/1`, `biomcp.cell_line_card/1`, `biomcp.cell_line_names/1`, `biomcp.cell_line_identity/1`, `biomcp.cell_line_xrefs/1`, `biomcp.cell_line_variants/1`, `biomcp.cell_line_chembl/1` and `biomcp.cell_line_assay_count/1`.

- Why: The slice method lands types and schema before adapters, and the accepted design with the cell line rulings fixes the records, the command tree and the page shapes.
- Starts from: cell-line.md's identity and scientific boundaries, proposed model and schemas, command tree and case map, with the cell line rulings, which win over the design text where the design retires `all`; the j14318 captures and 0256's witnesses; `rust-standards.md`; the existing `Curie`, `Capped` and ChEMBL ID types.
- Rules: source categories, variation types, mutation types and zygosity labels stay native strings, because the captures do not prove a closed vocabulary. A variation keeps every gene member, reference and provenance row, and a provenance row may be a PubMed reference, an institution or a database cross-reference, so no type requires a PMID. A free-text mutation description, a fusion or a coordinate spelling never becomes a normalized allele, reference sequence or assembly. A gene member yields an HGNC identity only where the source row carries one. Species and disease references stay source-qualified, and NCIt and ORDO identifiers stay independent. A warning is complete source text with its scope, never a classifier. A name is a display field and never a join key. A ChEMBL cell ID is a source-local cell identity, never a compound or target, and an assay count is never an activity, experiment or sensitivity count. Optional absence never means not fetched. There is no PharmacoDB, drug-response, HPA expression or gene cell-lines type.
- Proof: cases first. Type review checks each field's absence, multiplicity and collection scope against the j14318 cards and 0256's witnesses, including K-562's 1,398 cross-references, OCI-AML-3's NRAS row with database provenance and no PubMed reference, U-937's TP53 note and qualified warning, MOLM-13's two-gene fusion and MOLM-13's ChEMBL record with absent EFO and CLO. Round-trip tests cover the accession, the qualified source ID and the ChEMBL cell ID forms, and refusal of a malformed accession, an unqualified source ID, a zero or over-25 limit, a negative offset and each before-I/O failure. The generated schemas are checked in with snapshot and compatibility checks, and existing schemas stay unchanged. This ticket makes no provider call. No licensed content enters the repo. Then make landing-gate runs through pm job.
- Defers: executable help, Markdown parity and the shared request, step and envelope schema versions move to 0258, which registers cell line in the shared request.
- Changes: `crates/biodata/src/`, `crates/biomcp-types/src/`, their schemas and contract tests.
