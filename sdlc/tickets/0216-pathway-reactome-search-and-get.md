Depends on: 0209

## Outcome

`search pathway "Signaling by EGFR"` searches Reactome by default and returns a five-row page of native human pathway headers in native rank, each with its stable ID, native title and source-stated species, with the literal query echoed, the source outcome and the source total from `numberOfMatches`. The adapter requests one native window whose size this ticket fixes from 0206's measurement, keeps it in a pool with the source revision and request identity, and pages it locally with `--limit`, `--offset` and `--pool`, marking truncation against `numberOfMatches` when the window is smaller than the native total. `search pathway --top-level` returns the source-stated human top-level pathway headers. `search pathway --gene HGNC:1097` resolves the gene's UniProt accessions through the existing checked HGNC map, reads the landed Reactome UniProt-to-pathway mapping for each accession, and returns the whole revision-bound walk as pages. `get pathway R-HSA-5673001` returns the card with exact identity, native title, species, stable ID version, release, available sections and source terms. `get pathway R-HSA-5673001 summary` returns the whole native summary with its source citations.

- Why: questions 1 to 23 ask for an exact human pathway record and its source citation, and the 2026-10-26 pathway rulings make Reactome the default search source.
- Starts from: pathway.md's question bank, direct source evidence, harvest query table, delight questions, command table and case matrix; the 2026-10-26 pathway rulings, which win over the design text; 0206's witnesses and measured window; the landed Reactome mapping in `crates/biomcp-adapters/src/reactome/mod.rs` and `crates/biomcp-query/src/gene/sections/pathways.rs`; the shared transport, pools and next steps in `architecture.md` 4, 6.7 and 6.10; 0209's types and 0212's registry.
- Rules: the adapter uses only the paging and filter spellings that 0206 proved, and otherwise one native window. Every row passes a human species check and an accepted `Pathway` or `TopLevelPathway` class check even when the source relaxes filters, and a failing row drops with a problem. Native rank stays as sent, with no title reranking, synonym or literal-title promise. `next` never repeats a live request to rebuild a page. Only the reviewed endpoint-specific structured `NOT_FOUND` 404 that echoes the exact query means empty; a generic 404, HTML error or foreign query echo is a failed outcome. An unknown Reactome ID returns its genuine 404 as not found, and `R-HSA-140877` stays a historical-ID not found with no replacement search. The card compares the returned `stId`, species and class with the request and drops a mismatch with a problem that never enters the cache. A summary is never clipped and no clinical claim is extracted from it. The gene selector never extracts a symbol from a label, and an accession without an exact join stays a problem. No actionability label. Next steps follow architecture 6.10: a header page gives one get per header in source order, then the page step, then at most three others; the card gives `summary`, `genes` and `events` section steps only where the source supports them.
- Proof: outside-in cases first, watched to fail. Before adapter code, one bounded keyless pm job captures each case's exact request once, with zero retries, and records the replies. Questions 1 to 23 assert each exact `R-HSA` record, its title, `Homo sapiens` and its version on the capture date, and the cited PMID where the native card references one; the harvest queries assert native rank and the reported total, including the literal KRAS query whose first native row is Hippo; `Hemostasis` asserts a six-row native total with no truncation mark; `MAPK signaling` asserts a truncation mark against its native total; the sentinel `zzzzNoPathway0191` asserts the structured empty; `--top-level` asserts the 29 human records on the capture date and a terminal page; `--gene HGNC:1097` asserts BRAF's 16 native mappings across pages with no gap or duplicate; text with `--top-level` and text with `--gene` fail before I/O; an unknown ID and `R-HSA-140877` assert not found. Recorded 429, 500, timeout and broken-body cases assert a failed outcome with source and terms, never an empty page. The job measures each command in CLI and MCP output, starting from the design allocations of 700 tokens for a header page, 450 for the card, 900 for the summary and 700 for a gene mapping page, and each case gets a ceiling at measured size plus 15 percent, recorded in pathway.md; a measurement over its allocation goes to the PM before landing. Reactome database data use CC0, so captured replies may live in the repo. Then make landing-gate runs through pm job.
