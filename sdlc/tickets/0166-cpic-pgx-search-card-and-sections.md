## Outcome

`search pgx --gene DPYD --source cpic` sends `pair_view?genesymbol=eq.DPYD` with `Prefer: count=exact` and returns a five-row page of native pair headers with the source total from `Content-Range`, the echoed gene and source, and `--limit` and `--offset` paging natively in the order 0163 proved. `--cpic-level A` adds `cpiclevel=eq.A`. `get pgx --gene DPYD --source cpic` returns the compact gene identity card from `gene?symbol=eq.DPYD`. `get pgx --gene DPYD recommendations --source cpic` returns the gene-keyed rows from `recommendation_view?lookupkey->>DPYD=not.is.null` with native drug names, complete lookup keys, populations and comments, paged with `--section-limit` and `--section-offset`, and filtered natively by drug only if 0163 proved the `drugid` filter. `get pgx --gene CYP2D6 guidelines --source cpic` returns the native guideline summary references. `get pgx --gene TPMT diplotype --diplotype '*1/*3A' --source cpic` returns the complete native lookup result from `diplotype?genesymbol=eq.TPMT&diplotype=eq.*1/*3A`.

- Why: the first pharmacogenomic question asks which guidance CPIC tracks for a declared gene, and the 0153 rulings keep CPIC for pairs, the gene card, gene-keyed recommendations, guideline references and declared diplotype lookup.
- Starts from: pharmacogenomics.md's command tree, JSON body shapes, case map and offline projections, with the 0153 PM rulings and recheck amendments; the j12644 rows C01 to C28 and 0163's order and drug filter witnesses; the shared transport and adapter shape in `architecture.md`; 0164's types and 0165's registry.
- Rules: no positional search, no drug-name search and no local drug filter. A pair level, ClinPGx level and recommendation classification stay separate, and `B/C` stays as sent. A recommendation row never drops another gene in its lookup key, so a TPMT row keeps its NUDT15 context. A literal zero from a diplotype lookup stays a successful empty reply, and no notation is repaired. No phase, activity score or phenotype is calculated, and no missing second gene reads as normal. A website notice absent from the API, such as the July 2026 DPYD update, stays a stated limitation and is never applied as a correction. Next steps follow 0153 recheck amendment 2: pair search gives the page step, then the gene card, then `recommendations`, with no disambiguate step while pair get is deferred; the gene card gives `recommendations` and `guidelines`; help and diplotype lookup are never steps. No drug step comes from a native drug name.
- Proof: outside-in cases first, watched to fail. Before adapter code, one bounded keyless pm job captures each case's exact request once, with zero retries, and records the replies.
