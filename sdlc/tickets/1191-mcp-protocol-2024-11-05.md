# 1191 — mcp-protocol-2024-11-05

Status: OPEN.

Milestone: 7

## Outcome

An MCP client that sends `protocolVersion` `2024-11-05` in `initialize` gets `2024-11-05` back, over stdio and over HTTP, and can list and call tools. Replies under that revision carry no field the 2024-11-05 specification does not define.

## Why

A public report says every BioMCP release from 0.9.0 on fails the MCP handshake ("connection closed") on Windows and macOS, while 0.8.25 worked. On 1.0 main (23d82a4c3), a stdio `initialize` asking for `2024-11-05` is answered with `2025-11-25`, because `REVISIONS` lists only `2025-03-26` and later; a client that supports only `2024-11-05` then disconnects, as the lifecycle specification allows. Many MCP clients still send `2024-11-05`.

## Rulings

- `sdlc/decisions/2026-11-01-no-backwards-compatibility.md` line 9: the MCP protocol revisions BioMCP answers serve current clients of an outside protocol, and that ruling does not decide them. Adding a revision is not compatibility code for old BioMCP formats.

## Starts from

- Starts from:
  - `crates/biomcp/src/mcp/protocol.rs` `REVISIONS`;
  - `crates/biomcp/src/mcp/legacy.rs` `revision`;
  - `crates/biomcp/src/mcp/http.rs` and `crates/biomcp/src/mcp/http/metadata.rs`, where code indexes `REVISIONS`;
  - `crates/biomcp/src/mcp/current.rs`.
- The specifications: https://modelcontextprotocol.io/specification/2024-11-05 and https://modelcontextprotocol.io/specification/2025-03-26 (changelog).

## Decisions

- PM decision (2026-11-27): add `2024-11-05` after `2025-03-26`, so code that indexes the list keeps its meaning. The developer checks every use of `REVISIONS`.
- PM decision (2026-11-27): compare 2024-11-05 with 2025-03-26 from the specification's changelog. Any reply field that 2025-03-26 added, such as tool `annotations` or audio content, is left out for a 2024-11-05 session. Name each difference handled in the commit message.
- PM decision (2026-11-27): HTTP under 2024-11-05 follows that revision's transport rules only as far as the existing legacy HTTP path already serves 2025-03-26. If 2024-11-05 HTTP needs the old HTTP+SSE transport, it stays refused over HTTP and is supported over stdio only; say so in the commit and the HTTP-server docs.

## Keeps

- Keeps: replies under every revision already supported; the refusal of unsupported revisions.

## Proof

- Proof:
  - outside-in stdio and HTTP cases where `initialize` with `2024-11-05` returns `2024-11-05`, then `tools/list` and one `tools/call` succeed with no 2025-03-26-only fields;
  - the HTTP test in `crates/biomcp/tests/runner/http.rs` that expects `2024-11-05` to be refused instead uses a revision BioMCP does not support, such as `2024-10-07`;
  - `make landing-gate`.

## Defers

- Defers: revisions older than 2024-11-05 (none are in use).

## Changes

- Changes: `crates/biomcp/src/mcp/`, `crates/biomcp/tests/runner/http.rs`, `tests/cases/`, `docs/`.
