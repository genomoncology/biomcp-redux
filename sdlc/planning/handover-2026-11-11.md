## What the measurements say

`biomed-agent-bench/results/baseline-1.0.md` (build c2511ee90): accuracy ties curl; only the command line on the GPT model beats curl on tokens. Three causes: agents leave BioMCP for curl; the 17-tool mode has per-tool argument names that clients refuse before the server sees the call; searches come back partial because the drug-name lookup times out. The bench's typed-examples round showed working examples in the instructions cut refusals on the two tools that got them from about 20 a pass to 1 or 2, and changed nothing on the tools without examples.

Milestone 7's done-when is the bar: each BioMCP mode at least 20% fewer tokens than curl with no fewer right answers, on both models, across repeats. Nothing counts as an improvement until the bench shows it.

## Things that bit us

- `pm ticket land` publishes one commit per ticket. Any file row that names a branch commit (the secret-scan ignores in `release/secrets.ignore.jsonl`) breaks on landing, and the landing gate does not run `make secrets`. Run `make secrets` on main after any landing that adds recorded replies. Reported to the pm project (m33938).
- pm wants one branch per ticket. When one branch carries several tickets, land the named one and close the others with `pm ticket status ... COMPLETE --reason`.
- The persona grades in the bench were self-graded. The defects reproduce; the grades need a regrade by a different model.
- The bench runs inside a coding agent, not a chat client. Tool-name-prefix failures there are the harness's, not BioMCP's.
