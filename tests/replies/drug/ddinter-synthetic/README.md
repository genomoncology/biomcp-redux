# DDInter interactions: synthetic partitions

DDInter is a noncommercial source (CC BY-NC-SA), so this replay holds no real DDInter rows (0695, 0920). The fifteen partition files keep DDInter's download URLs and CSV header; every row is invented. Drug names read "Synthetic Anchor …" and "Synthetic Partner …", levels are chosen by hand, and the IDs DDInter9001 to DDInter9027 lie above every ID in DDInter's export (its highest was DDInter1972 when 0920 checked). Before 0920 the rows used DDInter1 to DDInter27, which are real IDs, and one pair (DDInter22 with DDInter23, Moderate) matched a real interaction; 0920 moved every ID up by 9000.

The rows keep what the cases rely on: DDInter9001 has four partners spread over the A, D, L and N partitions, one of them listed with the anchor second; the DDInter9003 and DDInter9004 pair appears in both orders; and every level (Major, Moderate, Minor, Unknown) occurs.
