# Antibody name lookup recordings

Public GET replies captured on 2026-11-27. Each recording retains the request
URL, capture time and HTTP status. The MyChem.info search replays project the
original hit IDs, scores and [Guide to PHARMACOLOGY](https://www.guidetopharmacology.org/download.jsp)
fields (CC BY-SA 4.0). The HTTP 404 for `187051801` is unchanged. For
`178101561`, the replay projects the different ID named in the HTTP 200
response. Nonessential publisher components were omitted from these projections.

The direct search and molecule replies are from [ChEMBL](https://www.ebi.ac.uk/chembl),
release ChEMBL_37, under [CC BY-SA 3.0](https://chembl.github.io/chembl-licensing/).
