# Drug names with spaces

Recorded on 2026-11-17 by `biomcp --fresh --record` without keys in pm job JOB, one record folder per call, merged; every reply is kept unchanged. The sources are public US government data (openFDA drug enforcement, Drugs@FDA and drug labels) and Open Targets and MyChem, whose data are open for any use.

Each call asks the selected source for a name it does not hold. The name lookup also reads MyChem for the names other sources state, so the replies include MyChem's answers for the same names.
