# Recommendations: synthetic Semantic Scholar rows

Semantic Scholar's API terms are noncommercial, so these replays hold no real Semantic Scholar rows (0695, 0920). In `single/` and `multi/` every recommended paper is authored: paper IDs are zero-padded hex, DOIs sit under 10.1234/synthetic, corpus IDs start with 900 and PubMed IDs with 99. `empty/` is a live reply with an empty list, so it holds no rows to replace. The `pubmed/` replies are real public records.
