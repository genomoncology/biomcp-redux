# Offline source reach fixtures

`make reach-check` runs these recordings through the CLI cases. Each case records the floor directly as a count or a set of identities from the pinned input. Exact counts or identities mean a floor of 100% for that slice. A reply reporting zero rows for a positive slice fails even if its status is `complete`. These floors apply to the sampled classes and inputs shown in the cases.

| Publisher | Fixture source and scope |
| --- | --- |
| NCBI ClinVar | [Variation-specific XML](https://www.ncbi.nlm.nih.gov/clinvar/docs/ftp_primer/), retrieved 2026-11-27 using the variation IDs in the census. Each recording contains one native archive from the batch. The expected SCV accessions come from its submission list. The selected records span 17 variation types and the classified review categories. The [unclassified](../../cases/variant/assertions-no-classification/reach/clinvar-no-classification.yaml) and [included-only](../../cases/variant/clinvar-included-only/reach/clinvar-included-only.yaml) cases pin two unclassified assertions and one including VCV accession, respectively. |
| ClinGen | [Open curation downloads](https://clinicalgenome.org/docs/terms-of-use/), retrieved 2026-11-27. Full validity, gene dosage summary, gene dosage evidence and region dosage downloads contain 3,741, 1,720, 1,541 and 516 data rows. The lookup assertions check each download separately after sync. HGNC and MyGene recordings are retained open lookup inputs from the existing ClinGen cases. |
| ClinGen Evidence Repository | [Summary classifications](https://erepo.clinicalgenome.org/evrepo/), sampled 2026-11-27. The linked-document slice retains its published CAid, classification and summary document ID. The [rows without document IDs](../../cases/variant/assertions-erepo-without-document/reach/erepo-without-document-id.yaml) are checked on their own and alongside a row with a document ID. |
| Open Targets | The [drug without mechanisms](../../cases/drug/opentargets-without-mechanisms/reach/opentargets-drug-without-mechanisms.yaml) pins its one published indication and the empty targets section. |
| ChEMBL | The [molecule family cases](../../cases/drug/chembl-forms/reach/rows-on-salt-forms.yaml) pin the recorded salt mechanisms and the indication count across parent and salt forms. |
| gnomAD | The [held alleles](../../cases/variant/population/held-alleles/reach/gnomad-held-alleles.yaml) pin variant IDs for VCF-style, rsID, ClinVar, genomic HGVS and transcript HGVS inputs. The [typed CAid case](../../cases/variant/population/caid-typed/reach/gnomad-held-alleles-by-caid.yaml) uses retained population source facts in a synthetic routing fixture. |
| GenCC | [Versioned submissions export](https://thegencc.org/download), retrieved 2026-11-27. The slice keeps every MLH1 submission, including rows submitted under MONDO, OMIM and Orphanet IDs. The gene route returns the current submissions by source identity. |
| CPIC | [Public pair view](https://api.cpicpgx.org/v1/pair_view), retrieved 2026-11-27. Each recording is the complete set of view rows for the named gene, in pair-ID order. Together the slices cover all eight levels in the view. |
| WikiPathways | [Published human pathway list](https://www.wikipathways.org/json/listPathways.json) and [metadata](https://www.wikipathways.org/json/getPathwayInfo.json), retrieved 2026-11-27. Human identity fields from the list are delivered in the search endpoint's shape with blank node and annotation strings. [WP5352 revision 142547](https://www.wikipathways.org/pathways/WP5352.html) exercises the 61 distinct Ensembl references in its GPML. The HGNC slice contains the original rows for those references. |
| ClinicalTrials.gov | [Published value lists](https://clinicaltrials.gov/api/v2/studies/enums), retrieved 2026-11-27. The status, study type, phase and intervention type codes are unchanged. Authored study envelopes exercise their native fields through trial detail, including the arms section. |
| FDA Purple Book | The October 2026 [shipped roster](../../../crates/biomcp-adapters/src/purple_book/README.md) supplies the application and presentation counts for each reference product's proprietary and proper names. The tests read the shipped CSV through the offline CLI. |

The landing gate's regular CLI cases also cover cBioPortal recurrence on [chromosome X](../../cases/variant/recurrence-chrx.yaml), [chromosome Y and mitochondrial DNA](../../cases/variant/recurrence-chry-mt.yaml), and [rows that cannot be compared](../../cases/variant/recurrence-uncomparable.yaml).

The regular cases also cover the [Reactome UniProt mapping](../../cases/pathway/uniprot-gene-egfr.yaml), [WikiPathways Entrez references](../../cases/pathway/wikipathways-genes.yaml), [WHO eEML published listings](../../cases/drug/who-eml.yaml) and [biologic drug identity recovery](../../cases/drug/antibody-name-recovery.yaml). WHO eEML is a live adapter with recorded responses and has no bundled roster.
