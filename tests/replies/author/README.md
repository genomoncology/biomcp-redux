# Authors: synthetic Semantic Scholar replies

Semantic Scholar's API terms are noncommercial, so these replays hold no real Semantic Scholar record (0695, 0920). In `papers/` and `synthetic/` every author and paper is authored: names such as "Repeated name", "Another candidate" and the common name "Louis Williams" used as search text, paper IDs made of one repeated letter, PubMed ID 12345678 and DOIs under 10.1234. Author IDs (123, 333, 456, 789, 901, 902, 999) are small numbers chosen by hand; Semantic Scholar numbers its authors, so a real author may hold the same number, but no reply carries anything about a real author. `empty-first-source/` holds a live search reply with an empty list, so it has no rows to replace. The other folders hold PubMed replies only, which are public.
