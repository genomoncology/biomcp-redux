# ClinGen actionability recordings

ClinGen's public adult and pediatric score summaries were downloaded on 2026-11-27. Each replay retains the native TSV header and the complete FGF23 row. SCN2A was absent from both downloads. The adult FGF23 row has empty outcome, intervention and score cells. The pediatric row has one scored pair.

The HGNC slices and validity and dosage recordings reuse the existing gene and pathway fixtures. The MyGene replies preserve the public source responses to the submitted NCBI Gene IDs. See [ClinGen terms of use](https://clinicalgenome.org/docs/terms-of-use/).
