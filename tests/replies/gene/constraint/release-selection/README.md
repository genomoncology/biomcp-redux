# gnomAD release selection

Synthetic v4.0 and v4.1 constraint tables. TP53 has different values in each release and different canonical and MANE Select rows in v4.1. BCR has a MANE Select row in v4.1 and none in v4.0. HGNC and the single-gene MyGene exchange come from the gene constraint replay. The MyGene batch combines its unmodified BCR and TP53 response rows.
