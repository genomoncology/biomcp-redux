# Recorded parity selections

Run `make parity-run PLAN=tests/parity/sample.json BASELINE=/absolute/biomcp OUT=/absolute/new-directory` with the released 0.9.3 executable. The command prints one summary and retains a JSON report, each command's complete stdout and stderr, byte counts and elapsed microseconds. It records executable hashes and keeps source provenance beside the raw output. The output directory must be new. Use a directory outside Git for retained evidence.

A plan selects harvested case steps. Each entry declares the old command, its parity spelling table, old global options, source routes and fact projections. `facts` maps current assertion pointers to released JSON pointers. Values and assertion operators come directly from the harvested case. Omit `assertion_pointers` to assess every assertion in the selected step. An explicit list bounds a sample; the report lists unselected assertion pointers. Missing projections produce assessment gaps on both sides and a nonzero exit. An assertion the old binary gets right and the new binary gets wrong also produces a nonzero exit. A baseline command error cannot establish that the baseline got a fact wrong.

Source routes name existing replay capture files and a source from the pinned released registry. Each route must match that source's reviewed endpoint variable and native host. The runner rejects an unknown endpoint or host before either binary runs. It creates one local HTTP peer per enabled baseline source and points its declared endpoint variable at that peer. It disables every other source from the exact released registry. The old child has an empty inherited environment. The released client ignores system proxies, so the baseline uses explicit endpoint overrides. No peer opens a provider connection or falls back to a live source. The new child uses the case runner's offline replay transport and an independent rejecting proxy guard. Recordings with a single successful JSON exchange can be routed unchanged. An optional `envelope` wraps that unchanged value under one named JSON property. An optional `count_field` supplies the recorded array length as required decoder metadata. This count describes the replay array and makes no claim about a live source total. Other endpoint declarations require reviewed released-source provenance. Secrets are never inherited.

`released-sources.json` retains the exact public registry from release source revision `5641de7d7b79b53872f8599dbb4dba22e611dcaf`, plus the reviewed endpoint declaration from that same revision. The route source ID and capture source ID remain separate publisher spellings. Unreviewed endpoint mappings are explicit isolation gaps, and the runner refuses them before launching commands.

The sample takes the full-summary assertion from `gene/braf.yaml`. The gene spelling table maps `gene definition` to `get gene`. Released 0.9.3 issues a MyGene symbol query and expects an object with a `hits` array. The current binary issues a MyGene batch POST and consumes an array directly. The sample supplies that recorded batch array unchanged under `hits` for the released request. The released decoder also requires `total`, so the route derives it from the recorded array length. It changes no source field or value. The evidence keeps the original capture, adapted body and received request. Open Targets is explicitly disabled because the sample assesses the MyGene summary alone. This is a check of summary retention across the two binaries, not a timing comparison of identical request plans.

The sample does not claim whole-case or whole-comparison success. The full run needs reviewed command routes and projections for the remaining harvested assertions. Followed actions, walks and MCP-only steps need equivalent released command mappings before they can be selected as direct questions. These missing mappings must remain assessment gaps in that run.

Run `python3 scripts/test_parity_runner.py /absolute/released-0.9.3 /absolute/new-evidence-root` for the scoped proof. It uses both actual executables, checks the generated verdicts against their retained raw outputs, verifies unchanged source values and checks that a missing projection cannot pass.
