# Blocking streaming calls

`SourceSpec::grpc` declares a method on the source's HTTPS origin. `Leg::grpc` checks source admission, mode, request bounds and the absolute leg budget before reserving one shared provider quota permit. The permit remains held through every message callback and the terminal result. The source adapter owns its quota declaration. This transport introduces no provider registration or key setting.

`Fetch` owns one lazy worker. Its bounded queue reserves a slot before copying a request. One runtime owns a bounded `JoinSet` of calls. Each call opens one TCP connection to one resolved address, performs any proxy CONNECT and target TLS handshake, and gives one explicit h2 connection to tonic's framing codec. It never constructs a reconnecting Channel or enters the HTTP retry loop. A callback may receive a prefix; callers must discard that prefix after any failure and publish only after the call succeeds. Callbacks must return promptly. The transport checks the absolute leg budget before and after each callback.

`Network` selects both HTTP and RPC routes. Its explicit proxy wins over the checked environment routes; bypass rules apply to those environment routes. HTTP and HTTPS proxies use the same platform certificate verifier and additive roots as the target. Proxy Basic authentication stays on CONNECT. Target credentials appear only in sensitive outgoing metadata. Incoming metadata is bounded and reduced to validated content type and gRPC status before tonic receives it. Provider messages, status descriptions and arbitrary trailers enter no returned error or diagnostic.

`Limits` owns queue capacity, active stream count, request bytes, message bytes, cumulative wire bytes, metadata bytes and rows, and HTTP/2 windows. The response channel contains one bounded message. Tonic codec buffers use bounded growth increments, and h2 enforces header and receive-window limits. The complete codec retains its separate tensor expansion and ZSTD workspace bounds. Memory for the worker's requests, codec buffers, response messages, metadata and windows grows with `queued_calls` and `in_flight_streams`; it does not grow with an unbounded task queue. Callers own their decoded outputs and must bound their retention. Platform socket buffers and fixed TLS/library workspace require the release cost measurements; these fixture defaults do not establish production workload sizes.

Every call carries its original absolute end through admission, quota, DNS, CONNECT, TLS, upload, messages and trailers. `grpc-timeout` conveys the remaining budget. Cancellation drops the call's connection future before acknowledging cleanup. A canceled queued call atomically refuses startup. Explicit shutdown closes admission, cancels and joins all network tasks, then joins the worker thread.

The system resolver is the sole exception. Its single blocking slot preserves hosts-file, VPN and platform DNS behavior. Queued lookups are aborted on cancellation. A started lookup may finish after the call deadline or worker shutdown under the system resolver timeout. The caller returns at its deadline, releases its permit and starts no stream afterward. The private stalled-DNS test exercises this cancellation boundary without changing machine DNS settings.

The raw callback API accepts live mode. The checked API below handles record, replay and cached offline reads. Offline calls start no worker or connection. This module makes no provider calls during its local fixture tests.

`GrpcEndpoint::checked` pins a schema identity and a freshness policy. Its default remains `Freshness::Never`; requests that select provider defaults must retain that policy. `Leg::grpc_checked` uses an independent `StreamDecoder` for every read. The decoder owns source identity, message ordering, exact declared counts and checked tensor completion. Its finalizer exposes a result only after the transport observes OK terminal status. Adapters must serialize requests stably, canonicalize protobuf maps and preserve repeated-field order.

The cache key hashes length-delimited protocol, authority, full method, pinned schema and exact credential-free request bytes. The ordinary SQLite cache stores only successful finalized streams with a versioned terminal marker. Cache reads enforce current wire, message and decoder limits. RPC failures receive no HTTP negative-cache treatment.

Capture spools a bounded prefix to a temporary file and publishes ordered binary sidecars before atomically publishing the exchange. The versioned RPC metadata retains safe numeric terminal status separately from typed interruption. Replay reserves a whole exchange, reads safe sidecars under current limits, advances the shared virtual clock and drives the same decoder and finalizer. Offline checks the cache before returning an offline refusal and never submits a worker command.
